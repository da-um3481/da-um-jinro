## PART 1. 입시 기초 이론

### 1. 대학입시의 구조

#### 1.1 한국 대학입시의 전체 그림

```
대학입시 = 수시모집(75%) + 정시모집(25%)
         └─ 9월 접수       └─ 12월 접수
         └─ 11월까지 결과  └─ 2월 등록

핵심 원칙:
✓ 수시 6회, 정시 3회(가/나/다군 각 1회) 지원 가능
✓ 수시 합격하면 정시 지원 불가
✓ 정시는 "수능 성적"만으로 결정
```

#### 1.2 2026학년도 주요 일정 (반드시 암기)

| 구분 | 일정 | 비고 |
|------|------|------|
| **수능시험** | 2025년 11월 14일(목) | D-Day |
| **수시 원서접수** | 2025년 9월 8일~12일 | 5일간 |
| **수시 합격자 발표** | 2025년 11월 중순~12월 중순 | 대학별 상이 |
| **수시 등록** | 2025년 12월 16일~19일 | 4일간 |
| **정시 원서접수** | 2025년 12월 29일~31일 | 연말 3일 |
| **정시 합격자 발표** | 2026년 2월 6일까지 | |
| **정시 등록** | 2026년 2월 9일~11일 | 3일간 |

#### 1.3 전형의 4가지 분류

```
전형 분류 체계:

1. 학생부교과 (30%) ─ "내신이 전부"
   └─ 내신 80~100% 반영
   └─ 수능최저 有/無
   
2. 학생부종합 (25%) ─ "스토리가 중요"
   └─ 서류(학생부) 100%
   └─ 면접 있는 경우 多
   
3. 논술 (5%) ─ "논술 실력이 역전 카드"
   └─ 논술 60~70%
   └─ 수능최저 높음
   
4. 정시(수능) (40%) ─ "수능 점수가 전부"
   └─ 수능 100% or 90% 이상
```

### 2. 4대 전형 완전 정복

#### 2.1 학생부교과 전형 (내신 싸움)

**✅ 이런 학생에게 추천:**
- 내신 1~3등급 (상위 10% 이내)
- 모의고사보다 내신이 좋은 학생
- 수능 최저만 맞추면 되는 대학 지망

**📊 합격 공식:**
```
합격 가능성 = (내신 성적 80%) + (수능 최저 충족 여부 20%)

예시:
서울대(없음) ─ 내신 1.0~1.5 필요
연세대(최저有) ─ 내신 1.5 + 최저 3합 5
고려대(최저有) ─ 내신 1.8 + 최저 2합 4
성균관대 ─ 내신 2.0~2.5
```

**🎯 상담 스크립트:**
```
"OO님, 현재 내신이 평균 1.8등급이시네요.
학생부교과 전형으로는 성균관대~서강대 수준이 가능합니다.
다만 연고대를 노리시려면 수능최저를 반드시 맞추셔야 해요.
국수영탐 중 2개 합 4등급이면 충분합니다."
```

**⚠️ 주의사항:**
- 2학년까지 내신이 안 좋으면 3학년 올려도 소용없음
- 수능최저 없는 대학(서울시립대 등)은 내신컷 더 높음
- 인문은 2.0 이내, 자연은 2.5 이내가 서울권 기준

#### 2.2 학생부종합 전형 (스토리 싸움)

**✅ 이런 학생에게 추천:**
- 내신 2~4등급이지만 비교과가 탄탄
- 특정 분야에 열정과 활동이 풍부
- 면접 준비 가능한 학생

**📊 평가 4대 역량:**
```
학생부종합 = 학업역량(30%) + 진로역량(30%) 
           + 공동체역량(20%) + 자기주도성(20%)

학업역량 체크포인트:
✓ 교과 성적 추이 (상승세인가?)
✓ 세특(세부능력 특기사항) 내용
✓ 심화과목 이수 여부

진로역량 체크포인트:
✓ 희망 전공과 활동의 일치도
✓ 3년간 일관된 관심사
✓ 진로 관련 독서/탐구

공동체역량 체크포인트:
✓ 동아리 활동 (리더십)
✓ 봉사활동의 진정성
✓ 협업 프로젝트 경험

자기주도성 체크포인트:
✓ 스스로 찾아서 한 활동
✓ 어려움 극복 경험
✓ 창의적 문제해결
```

**🎯 상담 스크립트:**
```
"OO님, 내신은 평균 3.2등급이지만 
컴퓨터공학 관련 활동이 정말 탄탄하시네요.
1학년부터 코딩 동아리, 2학년 앱 개발 프로젝트,
3학년 AI 탐구까지... 3년 스토리가 완벽해요.

학생부종합으로 서강대~중앙대 수준 도전 가능하고,
면접만 잘 준비하시면 충분히 붙으실 겁니다.
자소서는 '왜 이 활동을 시작했는지'에 집중하세요."
```

**⚠️ 주의사항:**
- 내신 4등급 후반부터는 비교과로도 커버 한계
- SKY는 내신 2.5 이내 + 비교과 필수
- 학교 밖 활동(학원 수상, 외부 봉사)은 기재 불가

#### 2.3 논술 전형 (역전 카드)

**✅ 이런 학생에게 추천:**
- 내신 3~5등급이지만 논리적 사고력 뛰어남
- 글쓰기/수리 문제풀이에 자신감
- 수능최저를 맞출 자신 있음

**📊 합격 공식:**
```
논술 전형 = 논술 60~70% + 학생부 30~40%

논술 100점 기준:
- 인문논술: 제시문 독해 + 논리적 서술 + 비판적 사고
- 수리논술: 수학 심화 문제 (미적분, 확률과 통계)
- 과학논술: 물리/화학/생명과학 융합 문제

수능최저:
연세대(원주) ─ 3합 6
경희대 ─ 2합 5 or 3합 6
중앙대 ─ 3합 6
한양대 ─ 최저 없음 (경쟁률 100:1)
```

**🎯 상담 스크립트:**
```
"OO님, 내신이 3.8등급이라 교과/종합은 어렵지만
모의고사는 항상 2등급대를 유지하시니
논술 전형이 답입니다.

경희대 논술(최저 3합 6)을 1지망으로,
한양대 논술(최저 없음)을 보험으로 쓰세요.
논술 학원 최소 6개월은 다니셔야 하고,
기출문제 10개년 풀이는 필수입니다."
```

**⚠️ 주의사항:**
- 논술 준비 시간 최소 6개월~1년 필요
- 수능최저 못 맞추면 100% 탈락
- 실질 경쟁률 30:1 이상 (최저 맞춘 인원만)

#### 2.4 정시(수능) 전형 (점수 싸움)

**✅ 이런 학생에게 추천:**
- 내신은 안 좋지만 수능 자신감 有
- 재수생
- 수시 올인했다가 실패한 경우

**📊 합격 공식:**
```
정시 합격 = 수능 표준점수 환산 점수

표준점수 이해:
- 원점수 ≠ 표준점수 (어려운 시험일수록 표준점수 높음)
- 백분위 ≠ 등급 (상위 4%까지 1등급)

주요대학 반영 비율:
서울대(인문) ─ 국30 수40 영20 탐10
서울대(자연) ─ 국20 수40 영20 탐20
연세대(인문) ─ 국33.3 수33.3 영33.3
고려대(자연) ─ 수35 과35 국15 영15

가군/나군/다군 배치:
가군 ─ 연세대, 서강대, 성균관대
나군 ─ 고려대, 한양대, 중앙대
다군 ─ 경희대, 서울시립대, 건국대
```

**🎯 상담 스크립트:**
```
"OO님, 6월 모의고사 성적 기준으로
백분위 국어 88 / 수학 92 / 영어 2등급 / 탐구 평균 90
이면 성균관대~한양대 라인입니다.

전략은 이렇게 가세요:
가군 - 성균관대(상향)
나군 - 한양대(적정)
다군 - 경희대(안정)

단, 수능에서 국어를 1등급(백분위 95 이상) 올리면
연고대 도전 가능합니다."
```

**⚠️ 주의사항:**
- 6월 모의고사 ≠ 수능 (수능이 더 어려움)
- 탐구는 1과목 망치면 치명적 (과목 선택 중요)
- 영어는 절대평가지만 1~2등급 차이 큼

```
3. 성장성:

✅ "1학년 4등급에서 시작해 스스로 개념서를 정리하고
    오답노트를 만들어 3학년 1등급까지 상승"
```

### 4. 수능 최저학력기준

#### 4.1 최저기준 이해하기

**수능 최저 = 수시 합격의 마지노선**

```
표기법 해석:
"3합 7" = 국수영탐 중 3개 영역 합 7등급 이내
"2합 5" = 국수영탐 중 2개 영역 합 5등급 이내
"4합 5" = 국수영탐 4개 영역 합 5등급 이내 (가장 쉬움)

예시:
연세대 학생부교과 "3합 5"
→ 국어 2등급 + 수학 2등급 + 영어 1등급 = 5 (합격)
→ 국어 1등급 + 수학 2등급 + 영어 3등급 = 6 (불합격)
```

#### 4.2 주요 대학 수능최저 한눈에

| 대학 | 학생부교과 | 학생부종합 | 논술 |
|------|-----------|-----------|------|
| **서울대** | (미운영) | 없음 | (미운영) |
| **연세대** | 3합 5 | 없음 | 3합 6 |
| **고려대** | 2합 4 | 없음 | 3합 6 |
| **성균관대** | 2합 5 | 없음 | 3합 6 |
| **서강대** | 3합 6 | 없음 | 3합 7 |

#### 10.3 전형별 적합도 해석

**교과/종합/정시/논술 4가지 점수 비교**

```
[ 패턴 1: 교과 > 종합 > 정시 > 논술 ]
예) 교과 90 / 종합 85 / 정시 75 / 논술 60

해석:
"OO님은 전형적인 '내신형' 학생입니다.
 학생부교과 전형에 강점이 있고,
 종합 전형도 가능하지만 교과가 더 유리합니다.
 정시는 백업용으로 생각하시고,
 논술은 추천하지 않습니다."

전략:
- 교과 4장 + 종합 2장
- 수능최저 충족에 집중
- 정시는 가/나/다 각 1장 준비

━━━━━━━━━━━━━━━━━━━━━━

[ 패턴 2: 종합 > 교과 > 정시 > 논술 ]
예) 종합 88 / 교과 80 / 정시 78 / 논술 65

해석:
"OO님은 '스토리형' 학생입니다.
 비교과 활동이 탄탄해서 학생부종합에 강점이 있고,
 교과도 나쁘지 않아 둘 다 활용 가능합니다.
 정시도 백업으로 나쁘지 않네요."

전략:
- 종합 3장 + 교과 2장 + 논술 1장
- 면접 준비 철저히
- 자소서에 비교과 스토리 강조

━━━━━━━━━━━━━━━━━━━━━━

[ 패턴 3: 정시 > 교과 > 종합 > 논술 ]
예) 정시 92 / 교과 75 / 종합 70 / 논술 68

해석:
"OO님은 '수능형' 학생입니다.
 모의고사 성적이 우수해서 정시가 가장 유리하고,
 수시는 보험 정도로 생각하시면 됩니다.
 수능만 잘 보면 원하는 대학 충분히 갑니다."

전략:
- 수시는 안정권 위주로 2~3장만
- 나머지 시간 수능 준비에 올인
- 정시 가/나/다 모두 상향 지원 가능

━━━━━━━━━━━━━━━━━━━━━━

[ 패턴 4: 논술 > 종합 > 정시 > 교과 ]
예) 논술 85 / 종합 78 / 정시 75 / 교과 65

해석:
"OO님은 '논술형' 학생입니다.
 내신은 다소 부족하지만 논리적 사고력이 뛰어나
 논술 전형으로 역전 가능성이 높습니다.
 논술 3장 + 종합 2장 + 정시 백업 전략 추천합니다."

전략:
```
