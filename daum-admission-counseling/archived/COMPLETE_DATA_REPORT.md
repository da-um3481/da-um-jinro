# DA.UM 진학상담 시스템 - 전체 입시 데이터 구축 완료 보고서

## 📊 프로젝트 개요

**DA.UM 진학상담 시스템**은 대한민국 입시 상담 전문가를 위한 데이터 기반 진학 지도 플랫폼입니다.

### 🎯 핵심 목표
- **40분 상담에 즉시 활용 가능한 전문가 도구**
- **감이 아닌 실제 데이터 기반 판단**
- **학부모 리포트 자동 생성**
- **중학생/고등학생 구분 설계**

### 3️⃣ 지역별 진학 전략

#### 부산권 (부산·울산·경남)
- **주요대학**: 부산대, 부경대, 동아대, 경성대
- **핵심전략**: 
  - 부산대 지역인재 내신 3.0 이내 도전
  - 부경대 해양계열 전국구 경쟁력
  - 의료계열 다수 (부산대, 동아대, 인제대)
  - 지역인재 전형 적극 활용

#### 대구·경북권
- **주요대학**: 경북대, 대구대, 영남대
- **핵심전략**:
  - 경북대 지역인재 내신 2.9 이내 도전
  - 의학계열 강세 (경북대 의·치대)
  - 지역인재 수능최저 완화
  - 경북대 중심 전략 수립

#### 경남권
- **주요대학**: 경상국립대, 인제대, 창원대
- **핵심전략**:
  - 경상대 지역인재 내신 3.5 이내 도전
  - 부산권 대학도 지역인재 자격 있음
  - 인제대 의·치·한의예과 고려
  - 수시+정시 조합 전략

### 5️⃣ 비교과 활동 카테고리 (7개)

#### 학교 내 활동 (5개)
1. **동아리활동** (가중치: 높음)
   - 평가기준: 전공 연계성, 지속성, 리더십, 성과
   - 우수사례: 3년간 과학탐구동아리 회장, 주도적 실험 설계

2. **학생회 자치활동** (가중치: 높음)
   - 평가기준: 리더십, 공동체 기여, 문제해결력
   - 우수사례: 학생회장, 학급 갈등 조정 시스템 구축

3. **교내 수상** (가중치: 중상)
   - 주요수상: 교과우수상, 학력경시대회, 토론대회, 과학탐구대회

4. **독서활동** (가중치: 중상)
   - 평가기준: 전공 연계성, 깊이, 비판적 사고
   - 우수사례: 전공 관련 도서 20권 이상, 세특 연계

5. **세특 기재** (가중치: 매우 높음)
   - 평가기준: 구체성, 심화도, 전공 연계성
   - 우수사례: 수학 미적분 심화 탐구, 실생활 문제 해결

#### 학교 외 활동 (2개)
1. **교육기부** (가중치: 중)
2. **대회 및 공모전** (가중치: 중하) - 학생부 미기재 대회는 평가 반영 안 됨
