🎯 등록 순서 (3단계)

1 엑셀 준비: 위 양식대로 30명 학생 정보 작성

2 복사: 엑셀에서 전체 선택 (헤더 포함) → Ctrl+C

3 붙여넣기: 학생 등록 페이지 → 입력창 클릭 → Ctrl+V → 미리보기 → 등록하기

💡 중요한 팁

1. 구분자는 탭(Tab)입니다
• 엑셀에서 복사하면 자동으로 탭으로 구분됩니다
• 손으로 입력할 때는 Tab 키를 누르세요

2. 헤더(첫 줄)도 함께 복사하세요
• "이름 학교 학년 프로그램 시작일" 이 줄도 포함!

3. 날짜 형식을 지켜주세요
• 2025-01-02 (이런 형식)
• 2025/01/02 (이것도 가능)

4. 프로그램명을 정확히
• "겨울방학 30일" (띄어쓰기 포함)
