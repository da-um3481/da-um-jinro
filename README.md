## 📋 프로젝트 개요

이 시스템은 중학생들의 자기주도학습 역량을 강화하기 위한 30일 챌린지 프로그램입니다. 
진단평가, 맞춤형 학습 계획, 실시간 학습 추적 등을 통해 학생들의 학습 효과를 극대화합니다.

### 🎯 핵심 목표

- **자기주도학습 습관 형성**: 30일간의 체계적인 학습으로 스스로 공부하는 습관 확립
- **맞춤형 학습 제공**: 진단평가 기반 수준별 학습 콘텐츠 제공
- **실시간 학습 관리**: 타이머 기반 학습 시간 추적 및 진도 관리
- **교사-학생 연계**: 교사 대시보드를 통한 실시간 학습 현황 파악

### 🌟 주요 특징

- ✅ **50문제 진단평가**: 5개 과목(수학, 영어, 국어, 사회, 과학) 수준별 평가
- ✅ **4주 학습 로드맵**: 주차별 맞춤 학습 계획 자동 생성
- ✅ **학습 타이머**: 과목별 45분 학습 + 10분 휴식 시스템
- ✅ **심화 학생 선행학습**: 3~4주차 자동 선행학습 모드 전환
- ✅ **교사 대시보드**: 학생별 학습 현황 실시간 모니터링
- ✅ **공교육 자료 연계**: EBS 강의, 교과서 기반 학습

## 🔌 RESTful API 사용

시스템은 테이블 데이터 관리를 위한 RESTful API를 제공합니다.

### API 엔드포인트

```javascript
// 1. 목록 조회 (페이징, 정렬, 검색)
GET /tables/{table}?page=1&limit=10&sort=-created_at&search=query

// 2. 단일 레코드 조회
GET /tables/{table}/{record_id}

// 3. 레코드 생성
POST /tables/{table}
Body: { field1: value1, field2: value2, ... }

// 4. 레코드 전체 수정
PUT /tables/{table}/{record_id}
Body: { field1: value1, field2: value2, ... }

// 5. 레코드 부분 수정
PATCH /tables/{table}/{record_id}
Body: { field1: new_value }

// 6. 레코드 삭제
DELETE /tables/{table}/{record_id}
```

### 사용 예시

```javascript
// 학생 과목 목록 조회
async function loadSubjects() {
    const response = await fetch('tables/subjects?limit=10&sort=-created_at');
    const data = await response.json();
    console.log(data.data); // 과목 배열
}

// 학생부 기록 추가
async function addRecord(recordData) {
    const response = await fetch('tables/student_records', {
        method: 'POST',
        headers: {'Content-Type': 'application/json'},
        body: JSON.stringify(recordData)
    });
    return await response.json();
}

// 학습 계획 수정
async function updatePlan(planId, updates) {
    const response = await fetch(`tables/study_plans/${planId}`, {
        method: 'PATCH',
        headers: {'Content-Type': 'application/json'},
        body: JSON.stringify(updates)
    });
    return await response.json();
}
```
