💡 효과적인 학습 방법

⏰ 시간 관리 TIP

  • ✓ 45분 집중 + 10분 휴식 (뽀모도로 기법)
  • ✓ 어려운 과목은 오전에, 쉬운 과목은 오후에
  • ✓ 하루 학습 계획을 아침에 세우기

📝 노트 정리 TIP

  • ✓ 핵심 키워드 중심으로 정리하기
  • ✓ 색깔 펜으로 중요도 표시
  • ✓ 복습 시 빈칸 채우기로 확인

🎯 집중력 향상 TIP

  • ✓ 스마트폰은 다른 방에 두기
  • ✓ 조용한 배경 음악(클래식, 백색소음)
  • ✓ 책상 정리하고 시작하기

🔄 복습 TIP

  • ✓ 당일 → 3일 후 → 일주일 후 복습
  • ✓ 문제 풀이로 이해도 확인
  • ✓ 친구에게 설명하면서 복습

❓ 자주 묻는 질문

로그인이 안 돼요!

이름을 정확히 입력했는지 확인해주세요. 띄어쓰기나 오타가 있으면 로그인이 되지 않아요. 그래도 안 된다면 선생님께 문의하세요!

타이머를 잘못 눌렀어요!

"완료" 버튼을 누르면 지금까지의 시간이 자동 저장됩니다. 다시 시작하려면 "시작" 버튼을 눌러주세요.

학습 기록은 어떻게 확인하나요?

메인 페이지 하단의 "이번 주 학습 통계"에서 요일별 학습 시간을 확인할 수 있어요. 선생님께서 작성한 피드백도 하단에서 볼 수 있습니다!

부모님이 제 학습 현황을 볼 수 있나요?

네! 학부모 포털에서 자녀 이름을 입력하면 학습 시간, 진도, 선생님 피드백을 모두 확인할 수 있어요.

스마트폰으로도 사용할 수 있나요?

물론이에요! 모바일에 최적화되어 있어서 스마트폰, 태블릿, PC 어디서든 편하게 사용할 수 있습니다.
