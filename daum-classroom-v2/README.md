# DA.UM Classroom V2 - 자기주도학습 플랫폼

> 학생 주도 학습 기록 + AI 코칭 + 교사 지원 통합 시스템

---

## 🎯 프로젝트 개요

**DA.UM Classroom V2**는 자기주도학습을 위한 완전히 새로운 플랫폼입니다.

### 핵심 철학
- ✅ **학생 주도성**: 학생이 스스로 학습 내용을 기록
- ✅ **교사 지원**: 교사가 미션 제시 & 자료 공유
- ✅ **AI 코칭**: 질문에 대한 즉각적인 피드백
- ✅ **데이터 기반**: 학습 시간 & 패턴 분석

---

## 🚀 핵심 기능 (4대 기능)

### 1. 📖 학습 일지 (Student-Led Learning Journal)
**학생이 주도적으로 학습을 기록합니다**

- 과목별 학습 내용 기록
- 학습 시간 측정
- 사진 첨부 (문제, 노트 등)
- 메모 & 느낀 점
- ✨ **클라우드 자동 동기화** (Google Sheets)

**차별점**: Google Classroom은 과제 제출만 가능하지만, DA.UM은 학생이 자유롭게 학습을 기록할 수 있습니다.

---

### ☁️ Google Sheets 연동 설정 (선택)

**1단계: Google Sheets 생성**
```
1. Google Sheets 새로 만들기
2. 이름: "DA.UM Classroom V2 데이터"
```

**2단계: Apps Script 배포**
```
1. 확장 프로그램 > Apps Script
2. apps-script-code.gs 파일의 코드 복사
3. 코드 붙여넣기
4. 배포 > 새 배포
5. 유형: 웹 앱
6. 액세스 권한: "모든 사용자"
7. 배포 URL 복사
```

**3단계: URL 설정**
```javascript
// js/google-sheets-api.js 파일 수정
const WEB_APP_URL = '복사한_배포_URL_여기에_붙여넣기';
```

**4단계: 테스트**
```
1. 학생 포털 접속
2. 우측 상단 동기화 상태 확인
3. ☁️ 온라인 = 성공!
4. 📱 오프라인 = LocalStorage만 사용
```

---

### 2. 🎯 학습 미션 (Learning Missions)
**교사가 주간 목표를 제시합니다**

- 주간/월간 학습 목표 설정
- 미션 설명 & 자료 추천
- 진행 상황 추적
- 완료/종료 상태 관리

**차별점**: 강제 과제가 아닌 권장 미션으로, 학생의 자율성을 존중합니다.

---

### 3. 📂 자료실 (Learning Materials)
**교사가 학습 자료를 공유합니다**

- PDF, 동영상, 문서, 이미지 등
- 과목별 분류
- URL 링크 방식
- 언제든지 다운로드 가능

**차별점**: Google Drive처럼 파일 관리가 아닌, 학습에 필요한 자료만 선별하여 제공합니다.

---

### 4. 🤖 AI 코칭 (AI Coaching)
**학생이 질문하면 AI & 교사가 답변합니다**

- 문제 사진 업로드
- 질문 텍스트 입력
- AI 자동 답변 (향후 구현)
- 교사의 추가 피드백

**차별점**: 학습 코치는 과목별 문제를 직접 해결할 수 없지만, AI를 활용하여 힌트와 해법을 제시할 수 있습니다.

## 🏗️ 시스템 구조

```
DA.UM Classroom V2
│
├── 학생 포털 (student.html)
│   ├── 학습 일지 작성
│   ├── 미션 확인
│   ├── 자료실 다운로드
│   └── AI 질문하기
│
└── 교사 대시보드 (teacher.html)
    ├── 학생 관리 & 통계
    ├── 전체 학습 기록 조회
    ├── 미션 생성 & 관리
    ├── 자료 추가 & 공유
    └── 질문 답변
```

## 📱 사용 방법

### 학생
1. `student.html` 접속
2. 이름 입력 후 로그인
3. 학습 일지 작성 (오늘 뭘 공부했는지)
4. 미션 확인 (이번 주 목표)
5. 자료실에서 학습 자료 다운로드
6. 궁금한 것 AI에게 질문

### 교사
1. `teacher.html` 접속
2. 학생 학습 현황 확인
3. 주간 미션 생성 & 배포
4. 학습 자료 업로드
5. 학생 질문에 답변
