5등급제의 영향

  • 동점자 증가 → 원점수와 세특의 중요성 극대화
  • 1등급 비율 감소 → 2등급도 충분히 경쟁력 있음
  • 상승 곡선 중요 → 꾸준함과 성실함이 핵심

전형별 전략

학생부교과전형

✅ 특징

  • • 교과 성적 50% 이상 반영
  • • 정성평가 도입 대학 증가 (건국대, 고려대, 서강대 등)
  • • 학교장 추천 필요 (수도권 대학)
  • • 서울대 지역균형: 일반고 학생만, 학교당 3명 추천

🎯 전략

  • • 모든 과목 성실히 (소홀한 과목 없도록)
  • • 성적 상승 곡선 만들기
  • • 정성평가 대비: 학업태도, 탐구력 보이기
  • • 수능 최저 반드시 확인

학생부종합전형

학업역량 (30%)

  • ✓ 학업성취도
  • ✓ 학업태도 (주도성)
  • ✓ 탐구력

진로역량 (40%)

  • ✓ 과목 선택 적절성
  • ✓ 전공 관련 성적
  • ✓ 노력과 열정

공동체역량 (30%)

  • ✓ 협력과 소통
  • ✓ 나눔과 배려
  • ✓ 리더십

  • • 1단계: 국수영탐 등급만 활용 (표준점수 X)

  • • 면접 대비 (인적성면접 확대)
  • • N수생 불리: 내신 강화 추세

생활기록부 작성 전략

✅ 좋은 세특 예시 (서울대 합격 수준)

"심화 문제 제시 시 끝까지 해결하려는 집중력과 탐구력을 보임. 답지와 다른 자신만의 풀이 방법을 개발하여 선생님께 설명함. 틀린 문제는 오답노트를 작성하고 왜 틀렸는지 분석함. 유사 문제를 직접 제작하여 친구들과 공유함. GeoGebra를 활용하여 그래프를 직접 그려보며 수학적 개념을 시각화함. 퍼지함수에 대한 관심으로 관련 강의를 듣고 보고서를 작성함."

❌ 나쁜 창체 예시

  • • 회장단 선거에 참여하여 한 표를 행사함
  • • 양성평등교육을 통해 인식 개선의 중요성을 깨달음
  • • 다문화교육에서 자신의 의견을 제시함

→ 개인 활동이 아닌 단체 활동만 하면 차별화 불가!

📝 창의적체험활동 핵심

1. 자율자치활동

"환경 문제에 관심을 가져 관련 서적을 읽고 생각을 정리하여 학급에서 발표함. 이후 설문조사를 실시하고 자료를 분석하여 환경 캠페인을 기획함. 포스터를 제작하고 학교에 부착하였으며, 기후에너지 국제협약 사이트에 정책 의견을 제출함."

✓ 독서 → 발표 → 설문 → 분석 → 캠페인 → 정책 제안 (1년 프로젝트)

2. 동아리활동

  • • 3개년 활동을 한눈에 평가
  • • 지속 → 확장 → 심화 흐름 보이기
  • • 개별 활동으로 차별화
  • • 독서와 연계

3. 진로활동 (가장 중요!)

  • • 자신의 역량을 가장 잘 드러낼 수 있는 부분
  • • 관심 분야 독서 + 발표/토론
  • • 확장된 탐구 활동
  • • 담임상담 내용도 기재 가능

심화탐구 활동 작성법

Step 1. 탐구 동기 (가장 중요!)

"왜 궁금했는가?"를 명확히

Step 2. 주제 선정 이유

구체적이고 명확하게

Step 3. 핵심 내용 간추리기

너무 길지 않게, 핵심만

Step 4. 준비 과정 구체화

  • • 어떤 자료를 참고했는가?
  • • 어떤 방법을 사용했는가?
  • • 어떤 어려움이 있었는가?

Step 5. 결론 도출

실패도 기록 가능 → 실패를 통한 성장 강조

Step 6. 교사와의 소통

담임/과목 교사에게 전달 → 공동체역량 향상
