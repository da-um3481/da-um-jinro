🚨 중요! 새 창에서 열기

⚠️ GenSpark 안에서 클릭하면 안 돼요!

GenSpark 왼쪽 메뉴에서
파일을 클릭하면
계속 GenSpark 화면만 나와요!

완전히 새로운 브라우저 창이 필요해요!

1

크롬(또는 엣지) 브라우저 열기

❌ 잘못된 방법:

• GenSpark 안에서 파일 클릭
• GenSpark 화면 안에서 주소 입력

✅ 올바른 방법:

• 바탕화면에서 크롬/엣지 새로 열기
• 또는 Ctrl+N (새 창)
• GenSpark가 아닌 완전히 새 창

2

주소창 찾기

브라우저 맨 위쪽에

주소를 입력하는 긴 칸이 있어요

(예: https://www.google.com 이런 게 보이는 곳)

3

이 주소 복사하기

아래 주소를 마우스로 드래그해서 선택하고

Ctrl + C 누르기

https://da-um3481.github.io/da-um-jinro/학생엑셀입력.html
4

주소창에 붙여넣기

1. 주소창을 클릭

2. Ctrl + A (전체 선택)

3. Ctrl + V (붙여넣기)

4. Enter 누르기

📸 올바른 화면 vs 잘못된 화면

❌ 잘못된 화면 (GenSpark):

• 왼쪽에 "New", "AI 받은 편지함", "허브" 메뉴
• 화면 전체가 GenSpark 스타일
• 이러면 안 돼요!

✅ 올바른 화면 (학생 등록 페이지):

• "학생 일괄 등록" 제목
• 큰 입력창
• "미리보기", "등록하기" 버튼
• GenSpark 메뉴 없음
• 이게 맞아요!
