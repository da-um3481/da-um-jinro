🔍 "Raw" 버튼 찾기

⚠️ 중요!

"Raw" 버튼은 파일을 열었을 때만 보여요!
파일 목록 화면에서는 안 보입니다!

1

GitHub 저장소 열기

https://github.com/da-um3481/da-um-jinro

↑ 클릭해서 열기

⬇️
2

파일 이름 클릭하기

파일 목록에서 학생 업로드.html 이라는 파일을 찾으세요

그 파일 이름을 클릭하세요!

⬇️
3

이제 "Raw" 버튼이 보여요!

파일 내용이 화면에 보이면

오른쪽 위에 버튼들이 있어요:

  • "Raw" ← 이거 클릭!
  • "Blame"
  • "Edit"
  • "Delete"
⬇️
4

완료! 페이지가 열려요!

"Raw" 버튼을 클릭하면

실제 학생 등록 페이지가 열립니다! 🎉

📸 화면이 이렇게 보일 거예요

1단계 화면: 파일 목록 (Raw 버튼 없음)

→ 학생 업로드.html

→ 학생 관리.html

→ 인덱스.html

2단계 화면: 파일 열림 (Raw 버튼 보임!)

→ 오른쪽 위에 "Raw" "Blame" "Edit" 버튼들

→ 아래에 HTML 코드

3단계 화면: Raw 클릭 후 (실제 페이지!)

→ 예쁜 학생 등록 페이지!

💡 더 쉬운 방법!

파일 목록에서 "학생 업로드.html" 파일의
정확한 이름을 복사해서 저에게 보내주세요!

그러면 제가 직접 접속할 수 있는 주소를 만들어드릴게요!

예: "학생 업로드.html" 또는 "학생업로드.html"
