📌 STEP 1: 지금 당장 할 수 있는 것 (5분)

1파일 확인하기

지금 이 화면이 보이는 것처럼, 여러 개의 HTML 파일이 있습니다. 이것들이 바로 당신의 시스템입니다!

파일 이름 이게 뭐하는 파일인가요?
student-portal.html 학생이 보는 화면 (학생용 포털)
index.html 선생님이 보는 관리 화면 (관리자 대시보드)
students.html 학생 명단 관리하는 화면
presentation-proposal-100days.html 학교에 보여줄 제안서 (프레젠테이션)

2파일 열어보기 (연습)

방법 1: 더블클릭

  • 파일 이름에 마우스를 가져다 대기
  • 왼쪽 마우스 버튼을 두 번 빠르게 클릭
  • 크롬이나 엣지 같은 인터넷 브라우저에서 열림
[여기에 파일 아이콘 그림이 있다고 상상하세요]
📄 student-portal.html ← 여기를 더블클릭!

📌 STEP 2: 시스템 테스트하기 (10분)

3학생 포털 테스트

지금 해보세요:

  1. student-portal.html 파일을 더블클릭하여 열기
  2. 화면에 "학생 이름" 입력창이 보임
  3. "김철수"라고 입력해보기
  4. "학습 시작하기" 버튼 클릭
  5. 국어, 영어, 수학, 과학 과목이 보이면 성공! ✅

4관리자 대시보드 테스트

지금 해보세요:

  1. index.html 파일을 더블클릭하여 열기
  2. 화면 상단에 "DA.UM 학습관리 시스템" 제목이 보임
  3. 학생 목록, 그래프 같은 것들이 보이면 성공! ✅

⚠️ 만약 안 열린다면?

  • 파일 이름을 마우스 오른쪽 버튼으로 클릭
  • "연결 프로그램" 또는 "Open with" 선택
  • "Chrome" 또는 "Microsoft Edge" 선택
  • 그래도 안 되면 저에게 말씀해주세요!

📌 STEP 3: 30명 학생 등록하기 (30분)

💡 이 단계가 가장 중요합니다!

학교에서 받은 학생 명단 30명을 시스템에 입력하는 과정입니다.

걱정 마세요. 천천히 하나씩 따라하면 됩니다.

5학생 명단 준비하기

학교에서 받아야 할 정보:

필요한 정보 예시
학생 이름 김철수, 이영희, 박민수...
학년 중1, 중2, 중3
EBS 학력진단 점수 (선택) 75점, 82점, 65점...
학부모 연락처 (선택) 010-1234-5678

6메모장에 정리하기 (임시 작업)

컴퓨터에서 메모장 열기:

  1. 키보드에서 윈도우 키 + R 동시에 누르기
  2. "notepad" 라고 입력하고 엔터
  3. 메모장이 열리면 이렇게 적기:
1. 김철수 / 중1 / 75점 / 010-1234-5678 2. 이영희 / 중2 / 82점 / 010-2345-6789 3. 박민수 / 중1 / 65점 / 010-3456-7890 ... (30명까지)

저장하기: Ctrl + S 누르고 "학생명단.txt"라고 이름 짓기

📌 STEP 4: 시스템에 학생 등록하기 (가장 중요!)

⚠️ 이 부분은 제가 도와드리겠습니다!

현재 시스템은 수동으로 학생을 한 명씩 추가해야 합니다.

하지만 제가 "엑셀 파일로 한 번에 등록하는 기능"을 만들어드릴 수 있습니다.

7지금 당장 가능한 방법 (수동)

  1. students.html 파일 열기
  2. "학생 추가" 버튼 클릭
  3. 학생 이름, 학년 입력
  4. "저장" 버튼 클릭
  5. 30명 모두 반복... (시간 오래 걸림 😥)

8제가 만들어드릴 더 쉬운 방법 (자동)

엑셀 파일로 한 번에 등록하기

  1. 엑셀에 학생 명단 30명 작성 (이름, 학년, 점수...)
  2. 엑셀 파일을 시스템에 업로드
  3. 버튼 클릭 한 번으로 30명 모두 등록 완료! ✅

👉 이 기능을 만들어드릴까요? "네" 라고 답하시면 바로 만들어드립니다!

📌 자주 묻는 질문 (FAQ)

Q1. 파일을 어디에 저장해야 하나요?

A: 바탕화면에 "DA.UM프로그램"이라는 폴더를 만들고, 거기에 모든 파일을 모아두세요.

폴더 만드는 법: 바탕화면 빈 곳에서 마우스 오른쪽 클릭 → 새로 만들기 → 폴더

Q2. 파일이 안 열려요!

A: 파일 이름 끝이 ".html"로 끝나는지 확인하세요.

안 보이면: 파일 탐색기 열기 → 보기 탭 → "파일 확장명" 체크박스 켜기

Q3. 학생이 30명이나 되는데 일일이 입력해야 하나요?

A: 아니요! 제가 "엑셀 파일로 한 번에 등록하는 기능"을 만들어드립니다.

저에게 "엑셀로 학생 등록 기능 만들어주세요"라고 요청하세요.

Q4. 학생들은 어떻게 접속하나요?

A: student-portal.html 파일을 학생들에게 보내면 됩니다.

나중에 인터넷 주소(URL)로 만들 수도 있습니다. (GitHub Pages - 무료)

Q5. 돈이 드나요?

A: 지금은 0원입니다! 학생 10명까지는 완전 무료로 사용 가능합니다.

30명 이상이면 월 5,000원 정도 들 수 있습니다. (나중에 고민해도 됨)
