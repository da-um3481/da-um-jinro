1. 개발 취지

💡 교육 현장의 절실한 문제

👨‍🏫 다움 교육관리자의 고민

"학생 한 명 한 명을 체계적으로 관리하고 싶은 마음은 간절하지만, 현실은 녹록지 않습니다."

  • ✓ 다수의 학생을 개별적으로 관리하는 것은 물리적으로 어려움
  • ✓ 방과 후나 주말에 누가 어떻게 공부하는지 알 수 없어 월요일에야 뒤늦게 파악
  • ✓ 학습 부진 학생을 중간고사 이후에야 발견하여 이미 격차가 크게 벌어진 상태
  • ✓ 체계적인 학습 데이터가 없어 학생 상담 시 "더 열심히 하자"는 말밖에 못함
  • ✓ 행정 업무에 시간을 빼앗겨 정작 학생 지도에 쏟을 시간이 부족 (2024 교육부 설문)

💡 디지털 시스템으로 교사의 본연의 역할 회복

  • ✓ 30초마다 자동 갱신되는 학생 학습 현황 → 실시간 모니터링
  • ✓ 과목별·학생별 학습 시간 자동 집계 → 데이터 기반 상담
  • ✓ 학습 부진 학생 조기 발견 → 적시 개입으로 격차 해소
  • ✓ 행정 업무 자동화 → 학생 지도에 집중할 시간 확보

"이제 방과 후에도 스마트폰으로 학생들의 학습을 확인하고 응원 메시지를 보낼 수 있어요. 교육관리자로서의 보람을 느낍니다." - 다움 교육관리자

🎓 학생의 진짜 고민: "잘하고 싶은데, 방법을 모르겠어요"

"공부 못하는 게 아니에요. 어떻게 공부해야 하는지 모르는 거예요."

  • ✓ 잘하고 싶은 마음은 간절하지만 무엇을 어떻게 공부해야 할지 막막함
  • ✓ 학원에서는 진도만 나가고, 혼자 공부하는 시간은 외롭고 힘듦 (코로나19 이후 더 심화)
  • ✓ "자기조절"이 가장 어렵다 - 스마트폰 유혹, 시간 관리 실패로 자책감만 늘어남 (KEDI 2024)
  • ✓ 학습 방향을 잡기 어렵고 나만 뒤처지는 것 같은 불안감에 시달림
  • ✓ 부모님께 물어봐도 교육과정이 바뀌어 제대로 된 조언을 받기 어려움
  • ✓ "공부가 재미없다"가 아니라 "방향을 모르겠다"는 것이 진짜 문제

💡 시스템이 학습 방향과 동행자가 되어줍니다

  • ✓ 매일 3과목 자동 배정 → "오늘 뭐 공부하지?" 고민 불필요
  • ✓ 45분 타이머 → 집중 시간 보장, 스마트폰 유혹 차단
  • ✓ 학습 캘린더 시각화 → 누적 성과를 눈으로 확인하며 성취감
  • ✓ 교사 실시간 피드백 → "혼자가 아니다"는 느낌, 지속 동기 부여
  • ✓ 30일 루틴 형성 → 습관화로 평생 학습 역량 확보

"처음엔 귀찮았는데 2주차부터 공부가 습관이 됐어요. 캘린더에 초록색 체크가 쌓이는 게 너무 뿌듯해요!" - 참여 학생

👨‍👩‍👧 학부모의 속마음: "비싼 학원비, 정말 효과 있을까?"

"매달 50만원씩 쓰는데, 성적은 그대로... 이게 맞는 건지 모르겠어요."

  • ✓ 2024년 사교육비 역대 최고 29.2조원 (통계청, 전년 대비 7.7% 증가)
  • ✓ 중학생 1인당 월평균 사교육비 42.8만원, 참여율 75.5% (통계청 2024)
  • ✓ 학부모 10명 중 8명 "사교육비 부담 크다" 응답 (교육부 2024)
  • ✓ 많은 비용을 쓰지만 성적 향상 여부는 불명확, 불안감만 가중
  • ✓ 자녀가 학원에서 무엇을 배우는지, 집에서 얼마나 공부하는지 파악 불가
  • ✓ 교육과정을 잘 몰라 학원 말만 믿고 따를 수밖에 없는 현실
  • ✓ "공교육만으로는 부족하다"는 불안감이 사교육 의존을 부추김

💡 공교육 중심 학습으로 사교육 부담 완화

  • ✓ 무료 공교육 플랫폼으로 사교육비 절감 (연간 500만원 이상 절약 가능)
  • ✓ 실시간 학습 데이터 확인 → 자녀가 "오늘 몇 시간, 어떤 과목" 공부했는지 투명하게 공개
  • ✓ 교사 피드백 확인 → 학교와 가정의 소통 강화, 신뢰 구축
  • ✓ 체계적 학습 루틴 → 학원 없이도 스스로 공부하는 힘 키움
  • ✓ 학부모 전용 페이지로 자녀 학습 현황 실시간 조회

"아이가 스스로 공부하는 모습을 보니 뿌듯합니다. 학습 현황을 투명하게 확인할 수 있어 좋습니다." - 참여 학부모

🏫 왜 공교육 강화가 절실한가?

⚠️ 심각한 사교육 의존 실태 (통계청 2024)

  • • 2024년 사교육비 총액 29.2조원 - 역대 최고치 경신 (전년 대비 7.7% 증가)
  • • 중학생 사교육 참여율: 75.5% (4명 중 3명)
  • • 중학생 월평균 사교육비: 42.8만원 (연간 513만원)
  • • 학부모 10명 중 8명: "사교육비 부담이 크다" (교육부 2024)
  • • 소득 수준에 따른 교육 격차 심화 - 고소득층은 월 70만원, 저소득층은 20만원
  • • 교원 94% "사교육 증가 체감" 응답 (2024 교원 설문)

💬 "사교육 없이는 불안하다"는 인식이 고착화되어 가정 경제를 압박하고 있습니다.

📚 연구로 입증된 사실: "사교육보다 자기주도학습이 효과적"

🔬 KDI 한국개발연구원 연구 (2023)

"사교육보다 자기주도학습의 수능 점수 향상 효과가 더 높다. 자기주도학습 경험이 많을수록 대학 학점, 최종 학력, 취업 후 임금까지 우월하게 나타남."

🔬 한국교육개발원 (KEDI) 연구 (2023)

"교육의 질은 사교육비가 아니라, 학교 수업의 충실함과 학생의 자기주도학습에서 결정된다. 공교육 정상화가 사교육비 경감의 근본 해법이다."

🔬 서울연구원 (2023)

"취약계층 대상 공교육 학습 플랫폼 '서울런' 도입 3년, 학습 역량 향상과 사교육비 감소에 실질적 효과 입증."

✨ 공교육 혁신의 방향: 학교가 중심이 되는 교육 생태계

학교 정규 수업이 튼튼하면, 사교육은 필요 없습니다. 사교육은 학교 수업을 '보충'하는 것이 아니라, 학교 수업이 중심이 되고 가정에서의 자기주도학습이 이를 뒷받침하는 구조가 바람직합니다.

  • ✓ 학교 수업 → 자기주도학습 → 교사 피드백의 선순환 구조 구축
  • ✓ 디지털 기술을 활용한 개별 맞춤형 학습 관리 (AI 디지털 교과서 시대 대비)
  • ✓ 학습 데이터 기반의 과학적 교육 설계로 공교육 신뢰 회복
  • ✓ 학생·교사·학부모가 함께하는 교육 공동체 구축
  • ✓ 무료 공교육 플랫폼으로 소득 격차 없는 평등한 교육 기회 제공

💡 "사교육 의존도를 낮추는 가장 확실한 방법은 공교육의 질을 높이는 것입니다. 디지털 기술로 이제 가능합니다." - 교육부 2025 혁신 계획

2. 프로그램 개요

❄️ 알뜰살뜰 겨울방학 사용기

겨울방학은 학기 중 부족했던 학습을 보충하고 새 학기를 준비하는 소중한 시간입니다. 하지만 많은 학생들이 방학 계획을 세우고도 실천하지 못하고, 막상 개학하면 후회하게 됩니다.

💡 이 프로그램이 특별한 이유

  • ✓ 30일 동안 매일 학습 루틴 형성 - 방학이 끝나도 계속되는 습관
  • ✓ 디지털 시스템이 학습 동행자 - 혼자가 아니라는 느낌
  • ✓ 교육관리자의 실시간 피드백 - 방학 중에도 학습 관리
  • ✓ 새 학기 자신감 UP - 겨울방학 알차게 보낸 성취감

3. 운영 방법

🔄 일일 학습 프로세스

1

학생 로그인 (이름 입력)

학생이 포털에 접속하여 이름과 학년 입력 → 자동으로 오늘의 학습 스케줄 생성

2

3과목 동시 표시

평일: 5개 과목 중 3과목 자동 배정 (순환 방식) / 주말: 주간 복습 과목 배정

3

과목 선택 및 학습 시작

원하는 과목 카드에서 "▶ 시작" 버튼 클릭 → 45분 타이머 가동 및 학습 시작

4

학습 내용 기록

학습 중 "오늘 배운 내용" 텍스트 박스에 요약 작성 (선택사항)

5

학습 완료

최소 30분 이상 학습 후 "✓ 완료" 버튼 활성화 → 클릭 시 기록 저장 및 피드백 제공

6

다음 과목 자동 안내

완료한 과목 카드 페이드아웃 → 다음 과목 카드 펄스 효과로 강조 표시
