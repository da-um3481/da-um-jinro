## 🎯 주요 기능

### 1️⃣ index.html (메인 페이지)
- 교사/학생 역할 선택
- 베타 버전 경고 표시
- 기존 DA.UM 포털 링크 제공

### 2️⃣ teacher.html (교사 대시보드)
**과제 생성 기능**:
- ✅ 과목 선택 (수학/영어/국어/과학/사회)
- ✅ 제목 입력
- ✅ 설명 (안내사항) 입력
- ✅ 마감일 설정
- ✅ 과제 배포 버튼

**과제 관리 기능**:
- ✅ 배포된 과제 목록 표시
- ✅ 과제별 완료한 학생 수 표시
- ✅ D-Day 카운트다운
- ✅ 과제 삭제 기능

### 3️⃣ student.html (학생 포털)
**로그인 기능**:
- ✅ 이름만 입력하면 입장
- ✅ LocalStorage에 사용자 정보 저장

**과제 확인 기능**:
- ✅ 전체/완료/미완료 과제 통계 표시
- ✅ 과제 목록 (제목, 설명, 마감일)
- ✅ D-Day 표시
- ✅ 완료 체크 버튼
- ✅ 완료 취소 기능

## 🧪 테스트 시나리오

### 시나리오 1: 교사가 과제 배포
```
1. teacher.html 열기
2. 과목: 수학
3. 제목: "이차방정식 연습문제 20개"
4. 설명: "교과서 p.45-52 참고하여 풀이 과정 작성"
5. 마감일: 내일 오후 6시
6. [과제 배포하기] 클릭
7. ✅ 성공 메시지 확인
```

### 시나리오 2: 학생이 과제 확인
```
1. student.html 열기
2. 이름: "홍길동" 입력
3. [입장하기] 클릭
4. ✅ 방금 배포한 과제 보임
5. D-1 표시 확인
6. [완료 표시] 클릭
7. ✅ 녹색 배경으로 변경
```

### 시나리오 3: 교사가 완료 현황 확인
```
1. teacher.html 새로고침
2. 과제 목록에서 "완료한 학생: 1명" 확인
3. ✅ 실시간 반영됨
```

## 💡 작동 원리

### 데이터 저장 (LocalStorage)
```javascript
// 과제 데이터 구조
{
  id: "assign_1737889200000",
  subject: "수학",
  title: "이차방정식 연습문제 20개",
  description: "교과서 p.45-52...",
  deadline: "2026-01-17T18:00",
  createdAt: "2026-01-16T12:30:00Z",
  completedBy: ["홍길동", "김영희"]  // 완료한 학생 목록
}
```

### 동기화 방식
- 교사가 과제 생성 → LocalStorage 저장
- 학생이 새로고침 → LocalStorage 읽기
- 학생이 완료 체크 → LocalStorage 업데이트
- 교사가 새로고침 → 업데이트된 데이터 확인

**주의**: 같은 브라우저에서만 동기화됨 (MVP 한계)
