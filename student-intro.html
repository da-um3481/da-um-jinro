📚 학습 포털 사용법

3분이면 끝! 간단해요 😊

시작하기

🎯 사용법은 딱 3단계!

1

내 이름 선택

포털 접속 → 상단에서 내 이름 선택

예시:
김민준
2

학습 시작하기

오늘의 체크리스트에서 "시작" 버튼 클릭

📐 수학
목표: 60분
⏱️ 시작 버튼을 누르면 타이머가 자동으로 시작돼요!
3

학습 완료하기

공부 끝나면 "완료" 버튼 클릭

📐 수학 (학습 중...)
45:30
시작: 14:30
✅ 완료 버튼을 누르면 자동으로 시간이 계산돼요!

💡 알아두면 좋아요!

📘

평일 (월~금)

4시간

학교 수업 복습 중심

📙

주말 (토~일)

6시간

주간 복습 + 문제풀이

자동으로 구분돼요!

오늘이 평일인지 주말인지 자동으로 인식해서 목표 시간이 바뀌어요.

⚠️ 이것만 주의하세요!

시작 버튼을 꼭 눌러주세요

공부 시작할 때 버튼을 눌러야 시간이 정확하게 측정돼요.

타이머가 계속 돌아가요

휴대폰을 꺼도, 다른 앱을 써도 타이머는 계속 돌아갑니다.

완료하면 수정 불가

완료 버튼을 누르면 다시 수정할 수 없으니 신중하게 눌러주세요.
