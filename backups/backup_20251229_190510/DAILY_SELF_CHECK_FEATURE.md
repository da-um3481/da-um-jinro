# 📝 하루 학습 완료 자기점검 기능

## 📋 개요

하루 학습 완료 후 **자기점검 모달**을 통해 학생이 오늘의 학습을 되돌아보고 내일을 준비할 수 있도록 돕는 기능입니다.

---

## 🎯 핵심 기능

### ✅ 자동 실행 흐름
1. **과목 학습 완료** (45분 타이머 완료)
2. **축하 모달** 표시 (XP 획득, 레벨업)
3. **메타인지 체크 모달** 자동 표시 (4가지 체크리스트)
4. **자기점검 모달** 자동 표시 ← **새로 추가됨!**

### 📝 고정 질문 3가지

#### 1️⃣ 오늘 학습 시작은 어땠나요?
- 😊 **쉬웠어요** - 바로 시작했어요
- 😰 **어려웠어요** - 시작이 힘들었어요

**목적**: 학습 시작의 어려움을 인식하고 다음날 개선 전략 수립

---

#### 2️⃣ 막힌 이유가 있다면?
- 📚 **내용이 어려웠어요**
- 🏠 **주변 환경 때문이었어요**
- ✨ **없었어요** - 잘 진행됐어요

**목적**: 문제의 원인을 파악하여 해결책 마련

---

#### 3️⃣ 내일 나의 행동 하나만 바꾼다면?
- 자유 텍스트 입력 (3줄)
- 예시:
  - "타이머 시작 전에 책상 정리하기"
  - "핸드폰을 멀리 두고 시작하기"
  - "30분마다 5분씩 휴식하기"

**목적**: 구체적이고 실행 가능한 작은 습관 개선 계획 수립

## 📊 교육적 효과

### 1. 자기성찰 능력 향상
- **매일 되돌아보기** → 학습 패턴 인식
- **문제 원인 파악** → 메타인지 발달
- **작은 개선 계획** → 실행력 향상

### 2. 학습 습관 개선
- **반복 문제 발견** → 패턴 인식
- **환경 최적화** → 집중력 향상
- **점진적 개선** → 지속 가능한 성장

### 3. 동기 부여
- **작은 성공 경험** → 자신감 상승
- **구체적 계획** → 불안감 감소
- **자율성 강화** → 학습 주도권 확보

## 🔧 기술적 구현

### JavaScript 함수
- `showDailySelfCheckModal()`: 모달 표시
- `closeDailySelfCheckModal()`: 모달 닫기
- `saveDailySelfCheck()`: 데이터 저장 (입력 검증 포함)
- `skipDailySelfCheck()`: 건너뛰기 (확인 팝업)

### HTML 요소
- `dailySelfCheckBackdrop`: 배경 오버레이
- `dailySelfCheckModal`: 모달 컨테이너
- 라디오 버튼: `name="startDifficulty"`, `name="blockedReason"`
- 텍스트 영역: `id="tomorrowAction"`

### CSS 클래스
- `celebration-modal-backdrop`: 배경 오버레이 스타일
- `celebration-modal`: 모달 컨테이너 스타일
- `hidden`: 숨김 상태
- `show`: 표시 상태
