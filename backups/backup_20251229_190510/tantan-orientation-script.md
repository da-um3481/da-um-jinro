## 🎨 기초탄탄 vs 일반 프로그램 차이 (1분)

### 🤔 뭐가 다른가요?

우리 학교에는 두 가지 학습 프로그램이 있어요:

#### 📚 **일반 30일 프로그램**
- 평균 수준의 학생들을 위한 프로그램
- 5과목 고르게 학습 (국어, 영어, 수학, 사회, 과학)
- 하루 2~3시간 학습
- 목표: 전반적인 실력 향상

#### 🌱 **기초탄탄 프로그램** ⭐ 오늘 배울 것!
- **기초가 부족한 학생**들을 위한 특별 프로그램
- **핵심 3과목** 집중 (국어, 영어, 수학)
- 하루 1~2시간으로 부담 없이
- 목표: **기초 실력을 탄탄하게!**

### 💡 이런 친구들에게 추천해요!

✅ "수학 공식이 뭔지 모르겠어요"
✅ "영어 단어 외우는 게 너무 어려워요"
✅ "국어 지문 읽으면 무슨 말인지 모르겠어요"
✅ "학원 진도는 너무 빠르고, 학교 수업은 못 따라가겠어요"
✅ "기초부터 천천히 다시 배우고 싶어요"

**여러분 중 하나라도 해당되나요? 그럼 이 프로그램이 딱이에요!** 💪

## 📊 3단계: 기초실력 진단받기 (2분)

### 🎯 진단평가가 왜 필요할까요?

로그인하면 가장 먼저 **기초실력 진단평가**를 받게 돼요.

**"또 시험이야?"** ❌
아니에요! 이건 시험이 아니에요!

이건 마치 병원에서 건강검진 받는 것과 같아요. 🏥
- 어디가 아픈지 → 어디가 부족한지 확인
- 어떤 치료가 필요한지 → 어떤 학습이 필요한지 파악

**절대 점수로 판단하지 않아요!**
그냥 여러분의 **현재 위치**를 확인하는 거예요. 📍

### 📝 진단평가 구성

기초탄탄 프로그램은 **3과목만** 집중해요!

- 📖 **국어** 10문제 (어휘, 문법, 독해 기초)
- 🌏 **영어** 10문제 (알파벳, 기초 문법, 간단한 단어)
- 🧮 **수학** 10문제 (기초 연산, 간단한 개념)

**총 30문제** (일반 프로그램은 50문제)

### ⏱️ 시험 규칙

- **시간 제한**: 없어요! 천천히 풀어도 괜찮아요
- **난이도**: 아주 기초적인 문제부터 시작해요
- **틀려도 괜찮아요**: 모르면 솔직하게 "잘 모르겠어요" 선택!

### 🎓 수준 판정

진단평가 결과로 3가지 수준으로 나눠져요:

#### 🌱 **기초 수준 (0~150점)**
→ **초등 고학년~중1 복습 추천**
- 초등학교 때 놓친 개념부터 다시
- 아주 천천히, 하나씩 배워요
- 걱정 마세요, 가장 많은 친구들이 여기서 시작해요!

#### ⚡ **보통 수준 (151~230점)**
→ **중1~중2 핵심 개념 집중**
- 중학교 기본 개념 탄탄하게
- 반복 학습으로 확실하게 내 것으로!

#### 🌟 **준비 완료 (231~300점)**
→ **중2~중3 심화 준비**
- 기초는 이미 갖춰졌어요
- 이제 일반 30일 프로그램으로 가도 될 것 같아요!

### 💡 진단평가 잘 보는 법

**DO ✅**
- 집중해서 문제 읽기
- 생각해서 답 고르기
- 모르면 솔직하게 "잘 모르겠어요" 선택

**DON'T ❌**
- 대충 찍지 말기
- 빨리 끝내려고 하지 말기
- 친구 답 베끼지 말기

**정확한 진단이 나와야 여러분에게 딱 맞는 학습을 추천할 수 있어요!** 🎯

## 📅 4단계: 매일매일 기초 다지기 (2분)

### 🎯 오늘의 학습 계획

진단평가가 끝나면, **매일 공부할 내용**이 자동으로 나타나요.

#### 📚 **3과목 학습 플랜**

| 과목 | 시간 | 내용 |
|------|------|------|
| 📖 국어 | 30분 | 어휘, 맞춤법, 짧은 글 읽기 |
| 🌏 영어 | 30분 | 기초 문법, 단어 암기, 간단한 회화 |
| 🧮 수학 | 30분 | 기본 연산, 개념 이해, 쉬운 문제 풀이 |

**총 1시간 30분** (일반 프로그램의 절반!)

💡 **부담 없죠?**
- 평일: 하루 1시간 30분만!
- 주말: 조금 더 해도 좋고, 쉬어도 괜찮아요!
- 못 한 날은 다음 날 조금만 더 하면 돼요!

### ⏱️ 똑똑한 타이머 기능

각 과목마다 **시작 버튼**이 있어요.

**이렇게 사용하세요:**

1. **과목 선택** (예: 수학)
2. **시작 버튼 클릭** 🟢
3. **타이머 작동** (여러분이 공부한 시간 자동 기록!)
4. **공부하는 동안** 다른 과목은 시작 못 해요 (집중하라고!)
5. **최소 20분** 공부해야 완료 버튼 누를 수 있어요

⏰ **왜 20분일까요?**
- 기초탄탄은 부담을 줄인 프로그램이에요
- 20분만 집중하면 충분히 효과 있어요!
- 처음엔 20분도 길게 느껴질 수 있어요. 괜찮아요!

### 📝 공부한 내용 간단히 메모하기

각 과목 아래에 **메모 칸**이 있어요.

**뭘 쓰면 될까요?**

```
✏️ 간단한 예시:

국어: 오늘 배운 단어 - 
- 포용: 너그럽게 감싸 안는다
- 암시: 직접 말하지 않고 슬쩍 알린다
→ 두 단어 헷갈렸는데 이제 알 것 같아요!

영어: be동사 복습
- I am, You are, He is
- 과거형 was, were도 배웠어요
→ 과거형이 어려워요 ㅠㅠ

수학: 분수의 덧셈
- 분모가 같으면 분자만 더하기
- 분모가 다르면 통분하기
→ 통분이 아직 어려워요
```

**이렇게 쓰면 좋아요:**
- 무엇을 배웠는지
- 어떤 게 쉬웠는지
- 어떤 게 어려웠는지

선생님이 여러분 메모를 보고 **더 좋은 피드백**을 줄 수 있어요! 💌

### Q1: 혼자서 할 수 있을까요? 😰

**A:** 괜찮아요!
- 다음 날 조금만 더 하면 돼요
- 완벽할 필요 없어요
- 꾸준히 하는 게 더 중요해요!

- 언제 어디서든 공부할 수 있어요
- 홈 화면에 추가하면 앱처럼 써요!
