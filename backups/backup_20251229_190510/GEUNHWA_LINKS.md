## 💾 데이터 저장

### localStorage 키
- `student_list` - 학생 목록
- `diagnostic_results` - 진단평가 결과
- `student_학생ID` - 개별 학생 데이터
- `learning_records` - 학습 기록

### 데이터 연동
- 학생 포털 ↔ 교사 대시보드 (진단평가)
- 학생 관리 ↔ 전체 시스템 (학생 정보)

---

## 🔄 주요 워크플로우

### 1. 프로그램 시작
```
학생 관리 시스템 → 학생 등록
    ↓
학생 포털 → 진단평가 실시
    ↓
교사 대시보드 → 결과 확인 및 수준별 분류
    ↓
학생 포털 → 맞춤 학습 스케줄 제공
```

### 2. 외부 공유
```
공유 페이지 → QR 코드 생성
    ↓
SNS/이메일/문자로 전송
    ↓
학교/학부모/교육청 접근
```

### 3. 일일 학습
```
학생 포털 로그인
    ↓
오늘의 학습 스케줄 확인
    ↓
과목별 타이머 사용
    ↓
학습 내용 기록
    ↓
학부모/교사가 대시보드에서 확인
```
