# 📚 입시 지도 페이지 활성화 자료

## 1. 대학 입시 전형 종류 및 특징

### 🎯 학생부교과전형
**특징:**
- 내신 성적 중심 평가 (80~100%)
- 비교과 영향력 적음
- 명확한 합격선 존재

**적합 학생:**
- 내신 1~2등급대 학생
- 성실하고 꾸준한 학습 태도
- 비교과 활동 부족해도 가능

**주요 대학:**
- 서울: 건국대, 동국대, 숙명여대, 성균관대(일부)
- 지방: 경북대, 부산대, 전남대 등 거점국립대

**준비 전략:**
- 내신 관리 최우선
- 수능 최저학력기준 충족 필수
- 1학년 때부터 계획적 관리

---

### 🌟 학생부종합전형
**특징:**
- 학생부 전반적 평가 (학업역량, 전공적합성, 인성, 발전가능성)
- 서류 + 면접 평가
- 정성평가로 역전 가능

**적합 학생:**
- 내신 2~3등급대 (상위권 대학 기준)
- 전공 관련 심화 활동 풍부
- 학업 성장세가 뚜렷한 학생
- 자기주도적 학습/활동 경험

**평가 요소:**
1. **학업역량** (40%)
   - 학업 성취도 (내신)
   - 학업 태도와 의지
   - 탐구력

2. **전공적합성** (30%)
   - 전공 관련 교과 이수 및 성취도
   - 전공 관련 활동과 경험
   - 전공에 대한 관심과 이해

3. **인성** (15%)
   - 협업능력
   - 나눔과 배려
   - 소통능력
   - 도덕성

4. **발전가능성** (15%)
   - 자기주도성
   - 경험의 다양성
   - 리더십
   - 창의적 문제해결력

**주요 대학:**
- SKY: 서울대(지균/일반), 연세대, 고려대
- 서울 상위권: 성균관대, 한양대, 중앙대, 경희대, 한국외대
- 지방거점: 경북대, 부산대, 전남대, 충남대

**준비 전략:**
- 1학년: 기초 학력 다지기, 다양한 경험
- 2학년: 전공 탐색, 심화 활동 시작
- 3학년: 전공 적합성 강화, 면접 준비

---

### 📝 정시(수능)전형
**특징:**
- 수능 성적 100% 반영
- 영역별 반영 비율 대학마다 상이
- 가채점 후 지원 전략 수립

**적합 학생:**
- 수능 모의고사 안정적 성적
- 내신 불리하지만 수능 강점
- 수능 집중 학습 가능한 학생

**수능 영역별 중요도:**
- **인문계열**: 국어, 영어, 수학(확통/미적), 사탐 2과목
- **자연계열**: 국어, 영어, 수학(미적/기하), 과탐 2과목
- **의약학계열**: 국어, 영어, 수학(미적), 과탐 2과목 (모두 1등급 필요)

**주요 대학 수능 반영:**
| 대학 | 인문 | 자연 |
|------|------|------|
| 서울대 | 국30/수35/영20/탐15 | 국30/수40/영20/탐10 |
| 연세대 | 국34/수33/영20/탐13 | 국22/수44/영20/탐14 |
| 고려대 | 국35/수35/영15/탐15 | 국25/수35/영15/탐25 |

**준비 전략:**
- 약점 과목 집중 보완
- 모의고사 철저 분석
- 시간 배분 전략 수립
- 가채점 후 정확한 지원

## 2. 학년별 입시 준비 로드맵

### 고1 (기초 다지기)
**1학기:**
- [ ] 내신 관리 시작 (전과목 골고루)
- [ ] 진로 탐색 (흥미, 적성 파악)
- [ ] 독서 습관 형성
- [ ] 학교 동아리 가입

**2학기:**
- [ ] 내신 성적 상승 곡선 만들기
- [ ] 전공 분야 결정 (대략적)
- [ ] 관심 분야 관련 활동 시작
- [ ] 겨울방학 심화 학습

---

### 고2 (본격 준비)
**1학기:**
- [ ] 내신 등급 안정화
- [ ] 전공 적합성 활동 본격화
- [ ] 세특 관리 (교과별 특기사항)
- [ ] 수능 기초 학습 시작

**2학기:**
- [ ] 목표 대학/학과 구체화
- [ ] 학생부 관리 (세특, 자율, 동아리)
- [ ] 수능 학습 본격화
- [ ] 겨울방학 수능 집중

---

### 고3 (최종 마무리)
**1학기:**
- [ ] 내신 1학기 올인
- [ ] 수시 지원 대학 리스트 작성
- [ ] 자기소개서 준비 (개요)
- [ ] 6월 모의평가 중요

**여름방학:**
- [ ] 자기소개서 작성
- [ ] 생활기록부 최종 점검
- [ ] 면접 준비 시작
- [ ] 수능 최종 점검

**2학기:**
- [ ] 9월: 수시 원서 접수
- [ ] 10월: 면접 준비 및 응시
- [ ] 11월: 수능 시험
- [ ] 12월: 정시 지원 전략

## 3. 전형별 합격 전략

### 학생부교과 합격 전략
```
✅ 핵심 체크리스트:
□ 내신 등급 계산 (학년별, 과목별)
□ 대학별 내신 산출 방법 확인
□ 수능 최저학력기준 충족 가능성
□ 경쟁률 및 합격선 분석
□ 6개 대학 전략적 배치
```

**지원 전략:**
- 상향 1곳: 목표 대학 (최저 충족 시 승부)
- 적정 3곳: 안정적 합격 가능 대학
- 하향 2곳: 확실한 합격 보장

---

### 학생부종합 합격 전략
```
✅ 핵심 체크리스트:
□ 전공 적합성 활동 정리
□ 학업 성장세 스토리
□ 인성/리더십 경험
□ 자기소개서 핵심 소재
□ 면접 예상 질문 준비
```

**서류 평가 대비:**
1. **학생부 스토리 구성**
   - 전공 선택 동기
   - 관련 활동의 연결성
   - 배우고 성장한 과정

2. **자기소개서 작성 팁**
   - 구체적 경험 중심
   - 배운 점과 느낀 점 강조
   - 전공 연계성 명확히

3. **면접 준비**
   - 학생부 기반 질문 대비
   - 전공 관련 시사 이슈
   - 인성 질문 (협력, 갈등해결)

---

### 정시 합격 전략
```
✅ 핵심 체크리스트:
□ 가채점 정확히 실시
□ 대학별 환산 점수 계산
□ 전년도 합격선과 비교
□ 추가합격 가능성 분석
□ 가, 나, 다군 전략 수립
```

**배치 전략:**
- **가군**: 상향 or 적정
- **나군**: 적정 or 안정
- **다군**: 안정 or 하향 (반드시 합격)

**변수 고려:**
- 이월 인원 (수시 미등록)
- 경쟁률 변화
- N수생 비율
- 추가합격 가능성

## 4. 주요 대학별 입시 특징

### 서울대
- **학종 비중 높음** (지역균형, 일반전형)
- 2단계 면접 비중 큼
- 학업능력 검증 철저

### 연세대
- 활동우수형: 다양한 경험 중시
- 면접 변별력 높음
- 최저 없음 → 경쟁 치열

### 고려대
- 학업우수형: 내신+비교과
- 계열적합형: 전공적합성
- 최저 있음

### 성균관대
- 학과모집 (전공 확정)
- 반영 과목 수 적음
- 최저 충족 필수

### 한양대
- 서류 100% 평가
- 면접 없음
- 활동의 질 중시

| 시기 | 일정 |

| 11월 중 | **수능 시험** |
| 12월 초 | 수시 합격자 발표 |
| 12월 말 | **정시 원서 접수** (가/나/다 각 3개) |
| 1~2월 | 정시 합격자 발표, 추가합격 |

## 8. 실전 활용 팁

### 학생 맞춤형 전략 수립
1. **성적 분석**: 내신 vs 수능 강점 파악
2. **활동 분석**: 학생부 강점 요소 추출
3. **목표 설정**: 현실적 목표 대학/학과
4. **전형 선택**: 유리한 전형 집중
5. **일정 관리**: 단계별 준비 계획

### 자주하는 실수 방지
❌ **피해야 할 것:**
- 무작정 상향 지원
- 최저학력기준 무시
- 자소서 복사/붙여넣기
- 면접 준비 소홀
- 정시 백업 무시

✅ **해야 할 것:**
- 데이터 기반 판단
- 복수 전략 준비
- 꾸준한 관리
- 전문가 상담 활용
- 심리적 안정 유지
