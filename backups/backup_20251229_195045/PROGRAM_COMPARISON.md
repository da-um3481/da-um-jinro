| 항목 | 겨울방학 30일 | 학기중 100일 |

## ✨ 공통 기능

### 1. 타이머 시스템 ⏰
- 과목별 45분 타이머
- 로그아웃 중에도 백그라운드 실행
- 자동 저장 (10초마다)
- 최소 학습 시간 30분
- 목표 달성 알림

### 2. 메타인지 체크 🧠
- 4가지 자기평가 체크리스트
- 이해도 텍스트 입력
- 어려웠던 내용 기록
- 다음 학습 계획 수립
- 자동 저장 및 점수 계산

### 3. 자기점검 시스템 📝
- 학습 시작 난이도 평가
- 막힌 이유 분석
- 내일 행동 계획
- 자동 저장

### 4. AI 피드백 🤖
- 학습 시간 분석
- 과목 순서 최적화
- 효율성 점수 (0-100)
- 강점 & 개선 제안
- 맞춤형 팁 제공
- 동기부여 메시지

### 5. 누적 복습 📚
- 에빙하우스 망각곡선 기반
- 1일, 3일, 7일, 14일 후 복습
- 자동 스케줄 생성
- 오늘의 복습 목록 표시

### 6. 학습 데이터 추적 📊
- 일별 학습 기록
- 과목별 시간 누적
- 완료 시각 기록
- XP & 레벨 시스템
- 연속 달성 일수 (Streak)

### 7. 캘린더 & 달성률 📅
- 월별 학습 캘린더
- 일별 달성 표시
- 진행도 시각화
- 학습 여정 로드맵

## 🆕 학기중 100일 전용 기능

### 🏫 학교 수업 기록 시스템

#### 오늘의 시간표
- **평일 자동 표시**: 월~금 시간표
- **주말 숨김**: 토~일은 시간표 없음
- **5과목 기본**: 수학, 영어, 국어, 과학, 사회, 역사, 기타

#### 수업 기록 입력
1. **과목 선택**: 드롭다운
2. **수업 내용**: 교과서 페이지 + 상세 내용
3. **이해도 선택**: 
   - 😰 어려워요
   - 🤔 보통이에요
   - 😊 잘 이해했어요
4. **질문 기록**: 선생님께 질문할 내용

#### 자동 통합
- **학교 수업 → 복습 자동 생성**
- 수업 기록 시 누적 복습 스케줄 자동 추가
- 학교 내용 + 자기주도 학습 통합 관리

#### 로그인 시 자동 로드
- 오늘의 수업 기록 표시
- 이해도별 색상 구분
- 질문 내용 강조 표시

#### 내신 직결 효과
- 수업 내용 기억률: **20-30% → 70-80%** (2-3배 증가)
- 복습 실행률: **10-20% → 80-90%** (자동 알림)
- 시험 범위 파악: 불명확 → 명확 (교과서 페이지)

## 🎓 사용 시나리오

### 겨울방학 30일 프로그램

**언제 사용?**
- 겨울방학/여름방학 기간
- 집중 학습 습관 형성
- 특정 과목 집중 공략

**하루 루틴**:
```
1. 로그인
2. 오늘의 학습 스케줄 확인 (자동 생성)
3. 과목별 타이머 학습 (45분)
4. 메타인지 체크
5. 자기점검
6. AI 피드백 확인
7. 오늘의 복습 완료
```

**목표**:
- 하루 3과목 이상
- 총 135분 이상 학습
- 매일 연속 달성
- 30일 완주

### 학기중 100일 프로그램

**언제 사용?**
- 학기 중 평일/주말
- 내신 대비 기간
- 학교 수업 내용 정리

**평일 루틴**:
```
1. 로그인
2. 오늘의 시간표 확인
3. 학교 수업 듣기
4. 방과 후 수업 내용 기록 (즉시!)
   - 교과서 페이지
   - 상세 내용
   - 이해도
   - 질문 사항
5. 자기주도 학습 (타이머)
6. 오늘의 복습 완료
7. 메타인지 체크
8. 자기점검
9. AI 피드백 확인
```

**주말 루틴**:
```
1. 로그인
2. 평일 수업 내용 복습
3. 자기주도 학습 (타이머)
4. 오늘의 복습 완료
5. 다음 주 준비
```

**목표**:
- 매일 학교 수업 기록 (평일)
- 하루 2과목 이상 자기주도 학습
- 총 90분 이상 학습
- 100일 완주

## 🔄 전환 가능?

### 겨울방학 → 학기중
**가능**: 데이터 자동 이전
- 학습 기록, 메타인지, 복습 스케줄 유지
- 학교 수업 기록 기능 추가됨
- 진행도는 새로 시작 (0일부터)

### 학기중 → 겨울방학
**가능**: 데이터 자동 이전
- 학습 기록, 메타인지, 복습 스케줄 유지
- 학교 수업 기록은 사용 안 함 (데이터는 유지)
- 진행도는 새로 시작 (0일부터)

**주의**: 
- 두 프로그램은 별도 URL
- 브라우저 LocalStorage는 도메인별로 분리
- 동일 도메인이므로 데이터 자동 공유됨
