### 2. 타이머 영속성 시스템 (Timer Persistence)

```
┌─────────────────────────────────────────────────────────────┐
│              ⏱️ 타이머 상태 관리 시스템                      │
├─────────────────────────────────────────────────────────────┤
│                                                             │
│  💾 localStorage 저장                                       │
│   ┌─────────────────────────────────────────┐             │
│   │  기초탄탄 포털 (tantan_student_data)     │             │
│   │  {                                       │             │
│   │    name: "학생이름",                     │             │
│   │    currentDay: 1,                        │             │
│   │    timers: {                             │             │
│   │      "1_수학": {                         │             │
│   │        elapsed: 2700,    // 45분        │             │
│   │        running: true,                    │             │
│   │        notified45: true                  │             │
│   │      }                                   │             │
│   │    },                                    │             │
│   │    lastAccessDate: "2025-12-28"         │             │
│   │  }                                       │             │
│   └─────────────────────────────────────────┘             │
│                                                             │
│   ┌─────────────────────────────────────────┐             │
│   │  일반 포털 (study_records)               │             │
│   │  [{                                      │             │
│   │    student_id: "student_123",            │             │
│   │    date: "2025-12-28",                  │             │
│   │    수학: {                               │             │
│   │      seconds: 1800,    // 30분          │             │
│   │      isRunning: true                     │             │
│   │    }                                     │             │
│   │  }]                                      │             │
│   └─────────────────────────────────────────┘             │
│                                                             │
│  🔄 상태 복원 로직                                          │
│   ┌─────────────────────────────────────────┐             │
│   │  페이지 로드 시                          │             │
│   │    ↓                                     │             │
│   │  localStorage 읽기                       │             │
│   │    ↓                                     │
│   │  날짜 비교                               │             │
│   │    ├─ 같은 날 → 타이머 상태 복원       │             │
│   │    └─ 다른 날 → 타이머 초기화          │             │
│   │    ↓                                     │             │
│   │  isRunning === true?                     │             │
│   │    ├─ Yes → 자동 재시작                 │             │
│   │    └─ No → 대기                         │             │
│   └─────────────────────────────────────────┘             │
│                                                             │
│  💾 자동 저장                                               │
│   - 타이머 tick마다 (1초)                                  │
│   - 완료 버튼 클릭 시                                      │
│   - 페이지 종료 시 (beforeunload)                         │
│                                                             │
└─────────────────────────────────────────────────────────────┘
```

### 3. 데이터 흐름도 (Data Flow)

```
┌──────────────┐
│ 학생 로그인   │
└──────┬───────┘
       │
       ▼
┌──────────────────────────────────────┐
│ localStorage에서 이전 데이터 로드    │
│  - studentData                        │
│  - study_records                      │
│  - timers                             │
│  - lastAccessDate                     │
└──────┬───────────────────────────────┘
       │
       ▼
┌──────────────────────────────────────┐
│ 날짜 비교                             │
│  lastAccessDate === today?            │
└──────┬───────────────────────────────┘
       │
       ├─ YES (같은 날)
       │   │
       │   ▼
       │  ┌──────────────────────────┐
       │  │ 타이머 상태 복원          │
       │  │  - elapsed 시간 복원     │
       │  │  - isRunning 복원        │
       │  │  - notified45 복원       │
       │  └──────┬───────────────────┘
       │         │
       │         ▼
       │  ┌──────────────────────────┐
       │  │ isRunning === true?      │
       │  └──────┬───────────────────┘
       │         │
       │         ├─ YES → 타이머 자동 재시작
       │         └─ NO → 대기
       │
       └─ NO (다른 날)
           │
           ▼
          ┌──────────────────────────┐
          │ 새 날짜로 초기화          │
          │  - elapsed = 0           │
          │  - running = false       │
          │  - notified45 = false    │
          │  - lastAccessDate = today│
          └──────────────────────────┘
```

## 💾 데이터베이스 구조 (localStorage)

### 스키마 다이어그램

```
localStorage
├─ tantan_student_data (기초탄탄 포털)
│   ├─ name: string
│   ├─ grade: number
│   ├─ currentDay: number (1~30)
│   ├─ studyLog: {
│   │    "1": {
│   │      "수학": { completed: boolean },
│   │      "영어": { completed: boolean },
│   │      "국어": { completed: boolean }
│   │    },
│   │    "2": { ... },
│   │    ...
│   │  }
│   ├─ timers: {
│   │    "1_수학": {
│   │      elapsed: number,      // 초 단위
│   │      running: boolean,
│   │      notified45: boolean
│   │    },
│   │    "1_영어": { ... },
│   │    ...
│   │  }
│   ├─ totalMinutes: number
│   └─ lastAccessDate: string    // "YYYY-MM-DD"
│
├─ studentData (일반 포털)
│   ├─ student_id: string
│   ├─ name: string
│   ├─ grade: string
│   ├─ class_num: string
│   ├─ number: string
│   ├─ created_at: string
│   └─ diagnostic_completed: boolean
│
├─ study_records (일반 포털 학습 기록)
│   └─ [{
│        student_id: string,
│        date: string,            // "YYYY-MM-DD"
│        수학: {
│          seconds: number,
│          isRunning: boolean
│        },
│        영어: { ... },
│        ...
│      }]
│
├─ activeSubject (일반 포털)
│   └─ string                     // 현재 학습 중인 과목
│
└─ currentStudentId
    └─ string                     // 현재 로그인한 학생 ID
```
