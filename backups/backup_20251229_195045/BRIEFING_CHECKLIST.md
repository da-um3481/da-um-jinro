## 📋 8. 예상 질문 & 답변

### Q1: 서버가 필요한가요?
**A**: 아니요! 모든 데이터는 학생 브라우저에 저장됩니다. GitHub Pages로 무료 호스팅됩니다.

### Q2: 40명에서 전체로 확장 가능한가요?
**A**: 네! 각 학교별로 독립적인 시스템이므로 무제한 확장 가능합니다.

### Q3: 데이터 보안은?
**A**: 모든 데이터는 학생 개인 브라우저에만 저장됩니다. 서버로 전송되지 않습니다.

### Q4: 모바일 지원은?
**A**: 네! 완전 반응형 디자인으로 스마트폰, 태블릿 모두 지원합니다.

### Q5: 비용은?
**A**: 완전 무료입니다. GitHub Pages 무료 호스팅을 사용합니다.

### Q6: 유지보수는?
**A**: GitHub를 통해 실시간 업데이트 가능하며, 모든 학교에 즉시 반영됩니다.
