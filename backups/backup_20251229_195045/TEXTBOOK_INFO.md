## 💡 근화여중 학생들을 위한 안내

### 1. 정확한 교과서 확인 방법
```
✅ 학교 가정통신문 확인
✅ 학교 홈페이지 공지사항
✅ 담임 선생님께 문의
✅ 교과서 표지 확인 (출판사, 저자명)
```

### 2. 포털 시스템 사용 시
```
1단계: 내 교과서 등록
  → 과목 선택
  → 출판사 선택 (위 목록 참고)
  → 저자 선택 (선택사항)
  → 총 페이지 수 입력

2단계: 학습 시 페이지 기록
  → 오늘 학습 페이지 입력
  → 예: 23~45쪽

3단계: 진도 자동 계산
  → 시스템이 자동으로 진도율 표시
```

### 3. 학년별 특징
```
중1: 2022 개정 교육과정 (2025년부터)
중2: 2015 개정 교육과정 (2024년 기준)
중3: 2015 개정 교육과정 (2024년 기준)
```
