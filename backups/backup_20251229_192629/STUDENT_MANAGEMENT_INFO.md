# 👥 학생 관리 시스템

## 📋 개요
근화여중 겨울방학 자기주도학습UP 챌린지를 위한 학생 관리 시스템입니다.  
학생 정보를 개별 입력하거나 엑셀로 일괄 등록할 수 있으며, 등록된 학생 목록을 효율적으로 관리할 수 있습니다.

## 🔗 접속 링크
- **직접 접속**: https://da-um3481.github.io/da-um-jinro/student-management.html
- **통합 포털**: https://da-um3481.github.io/da-um-jinro/unified-portal.html (관리 > 학생 관리 시스템)
- **공유 페이지**: https://da-um3481.github.io/da-um-jinro/geunhwa-share.html

## ✨ 주요 기능

### 1️⃣ 개별 학생 입력
- **필수 정보**: 학년, 반, 번호, 이름, 학생ID
- **선택 정보**: 성별, 연락처, 이메일, 학부모 연락처, 특이사항
- **실시간 유효성 검사**: 입력 오류 방지
- **중복 체크**: 동일 학생ID 중복 등록 방지

### 2️⃣ 엑셀 일괄 입력
- **지원 형식**: .xlsx, .xls, .csv
- **드래그 앤 드롭**: 파일을 끌어서 놓기만 하면 업로드
- **엑셀 양식 다운로드**: 표준 양식 제공
- **샘플 데이터**: 테스트용 샘플 데이터 자동 생성
- **미리보기**: 업로드 전 데이터 확인
- **중복 검사**: 기존 학생과 중복 체크

### 3️⃣ 학생 목록 관리
- **통계 대시보드**: 전체/학년별 학생 수 표시
- **검색 기능**: 이름, 학생ID로 실시간 검색
- **학년 필터**: 중1/중2/중3 선택 필터
- **편집/삭제**: 개별 학생 정보 수정 및 삭제
- **엑셀 내보내기**: 등록된 학생 목록 엑셀 다운로드
- **전체 삭제**: 모든 데이터 일괄 삭제 (확인 필요)

|------|-----|------|------|---------|------|------------|---------|--------------|----------|

### 필수 컬럼 (Required)
- 학년
- 반
- 번호
- 이름
- 학생ID

### 선택 컬럼 (Optional)
- 성별 (M/F)
- 연락처
- 이메일
- 학부모연락처
- 특이사항

## 💾 데이터 저장
- **저장 방식**: 브라우저 localStorage 사용
- **저장 키**: `student_list`
- **데이터 포맷**: JSON 배열
- **영구 저장**: 브라우저를 닫아도 데이터 유지

## 🎨 UI/UX 특징
- **다크 테마**: 눈의 피로를 줄이는 현대적 디자인
- **반응형 디자인**: 데스크톱, 태블릿, 모바일 모두 지원
- **애니메이션**: 부드러운 화면 전환 효과
- **토스트 알림**: 작업 결과 즉시 피드백
- **아이콘**: Font Awesome 6.4.0 사용

## 📱 사용 시나리오

### 시나리오 1: 개별 학생 등록
1. "개별 입력" 탭 선택
2. 학생 정보 입력 (필수 항목 체크)
3. "학생 등록" 버튼 클릭
4. 성공 메시지 확인

### 시나리오 2: 엑셀로 대량 등록
1. "엑셀 일괄 입력" 탭 선택
2. "엑셀 양식 다운로드" 버튼으로 양식 받기
3. 엑셀에 학생 정보 입력
4. 파일을 드래그하여 업로드 영역에 놓기
5. 미리보기에서 데이터 확인
6. "N명 학생 등록" 버튼 클릭

### 시나리오 3: 학생 검색 및 관리
1. "학생 목록 관리" 탭 선택
2. 검색창에 이름이나 학생ID 입력
3. 학년 필터로 특정 학년만 표시
4. 수정/삭제 버튼으로 개별 관리
5. "엑셀 내보내기"로 전체 목록 다운로드

## 🔄 다른 시스템과의 연동
- **학생 포털**: `student_list` 데이터를 학생 포털에서 참조 가능
- **교사 대시보드**: 학생 목록을 교사 대시보드에서 활용
- **학부모 대시보드**: 학생 정보를 학부모 화면에 표시

## 🛠️ 기술 스택
- **HTML5**: 시맨틱 마크업
- **CSS3**: Grid, Flexbox, 애니메이션
- **JavaScript**: Vanilla JS (프레임워크 없음)
- **XLSX.js**: 엑셀 파일 처리 (v0.18.5)
- **Font Awesome**: 아이콘 라이브러리 (v6.4.0)

## 📈 통계 기능
- 전체 학생 수
- 학년별 학생 수 (중1, 중2, 중3)
- 실시간 카운트 업데이트

- 클라이언트 측 저장 (localStorage)
- 서버 전송 없음
- 브라우저 내에서만 데이터 보관
- 개인정보 암호화 없음 (주의: 민감 정보 입력 시 주의 필요)
