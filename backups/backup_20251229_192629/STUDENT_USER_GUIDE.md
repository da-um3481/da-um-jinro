## ⏰ 학습하기 - 타이머 사용법

### 1️⃣ 과목 선택하고 시작
1. "오늘의 학습 스케줄"에서 과목 선택
2. **[시작 →]** 버튼 클릭
3. 타이머가 **0:00**부터 시작돼요

```
📝 수학 타이머
━━━━━━━━━━━━━━━━
⏱️ 15:23 / 목표 45:00
진행률: ▓▓▓▓▓░░░░░ 34%

[일시정지] [완료]
```

### 2️⃣ 학습 내용 입력
타이머 아래에 오늘 배운 내용을 적어요:

```
📖 학습 내용
━━━━━━━━━━━━━━━━
오늘은 이차방정식 근의 공식을 배웠어요.
x = (-b ± √(b²-4ac)) / 2a
```

**💡 꿀팁**: 
- 나중에 복습할 때 이 내용을 볼 수 있어요!
- 간단하게 적어도 돼요

### 3️⃣ 타이머 규칙 ⚠️ 중요!

#### ✅ 좋은 점
- **최소 30분** 이상 학습해야 완료 가능
- **45분** 목표 달성 시 알림
- **로그아웃**해도 타이머는 계속 실행
- **10초마다** 자동 저장

#### ❌ 주의사항
- 30분 미만에 완료 누르면 "조금 더 학습해주세요!" 알림
- 다른 과목으로 바꿀 수 없어요 (완료 후 가능)
- 핸드폰 꺼도 타이머는 계속 실행돼요! (시작 시각 기준)

## 🧠 메타인지 체크 (자동 실행)

축하 모달을 닫으면 **자동으로** 메타인지 체크가 나타나요!

### 4가지 체크리스트
```
✅ 배운 내용을 말로 설명할 수 있나요?
✅ 친구에게 가르쳐줄 수 있나요?
✅ 비슷한 문제를 혼자 풀 수 있나요?
🔄 이 부분은 다시 복습이 필요한가요?
```

### 간단 메모 (선택)
```
📝 잘 이해한 내용: 근의 공식 적용 방법
📝 어려웠던 내용: 판별식 개념
📝 다음 학습 계획: 내일 판별식 문제 5개 풀기
```

**💡 왜 중요한가요?**
- 내가 진짜 이해했는지 확인
- 약한 부분을 빨리 발견
- 학습 효과 **2배** 증가!

   ⚪ 🏠 주변 환경 때문이었어요
   ⚪ ✨ 없었어요 - 잘 진행됐어요

3️⃣ 내일 나의 행동 하나만 바꾼다면?
   📝 핸드폰을 서랍에 넣고 시작하기
```

## 🤖 AI 피드백 (자동 실행)

자기점검을 제출하면 **자동으로** AI 피드백이 나타나요!

### AI가 분석하는 것들
1. 📊 오늘 학습 시간 & 과목 수
2. 🔄 과목 순서 (어려운 과목 먼저?)
3. 📝 자기점검 응답
4. 💯 효율성 점수 (0-100점)

### 피드백 예시
```
🌟 완벽한 하루였어요!
━━━━━━━━━━━━━━━━
오늘 3개 과목을 2시간 15분 동안 학습했어요.
효율성 점수는 85점입니다.

✨ 오늘의 강점
• 학습 시작이 수월했어요! 좋은 습관이 자리잡고 있어요.
• 막힘 없이 학습이 진행됐어요! 집중력이 훌륭해요.
• 3개 과목을 균형있게 학습했어요!

💡 개선 제안
• 현재 학습 방식이 효과적이에요. 이대로 유지하세요!

🚀 내일을 위한 팁
• 💡 당신의 계획: "오늘처럼 9시에 시작하기"
• 🔄 45분 학습 + 10분 휴식 사이클을 추천해요!

💬 매일 조금씩 나아지는 것이 진짜 성장이에요! 🌱

[확인했어요! 내일도 파이팅! 💪]
```

**💡 데이터 기반 코칭**
- 객관적 분석으로 개선점 발견
- 맞춤형 조언
- 매일 다른 동기부여 메시지

🚀 가속러 배지      (13-18일)
💐 개화 배지        (19-24일)
👑 완주 트로피      (25-30일)
```

## 💡 자주 묻는 질문 (FAQ)

### Q1: 타이머를 멈출 수 없나요?
**A**: 일시정지는 가능하지만, 완료하려면 최소 30분 필요해요. 이유는?
- 집중력: 30분은 뇌가 집중 상태에 들어가는 최소 시간
- 효과: 짧은 학습은 기억에 잘 안 남아요
- 습관: 꾸준히 긴 시간 학습하는 습관 형성

**💡 꿀팁**: 포모도로 기법 (25분 학습 + 5분 휴식)을 활용하세요!

---

### Q2: 로그아웃하면 타이머가 멈추나요?
**A**: 아니요! 타이머는 **계속 실행**돼요.
- 시작 시각을 기록해서 경과 시간 계산
- 재로그인하면 자동으로 복원
- 예: 10분 학습 → 로그아웃 → 20분 후 재로그인 → 30분으로 복원

**💡 안전**: 핸드폰 꺼져도, 브라우저 닫아도 OK!

---

### Q3: 메타인지/자기점검을 건너뛸 수 있나요?
**A**: 네, 가능해요. 하지만 **강력 비추천**!
- 메타인지: 학습 효과 2배 증가
- 자기점검: 습관 개선의 핵심
- AI 피드백: 맞춤형 조언 제공

**💡 추천**: 처음엔 귀찮아도 2주만 하면 습관됩니다!

---

### Q4: 30일/100일을 다 못 채우면 어떻게 되나요?
**A**: 아무 문제 없어요!
- 중간에 시작해도 OK
- 며칠 쉬어도 OK (연속 달성만 끊김)
- 자기 페이스대로 진행하세요

**💡 목표**: 완벽보다 꾸준함이 중요해요!

---

### Q5: 데이터가 삭제되나요?
**A**: 브라우저 LocalStorage에 저장돼요.
- 같은 브라우저 사용 시 영구 보관
- 브라우저 캐시 삭제 시 삭제될 수 있음
- 다른 기기는 동기화 안 됨

**💡 백업**: 주기적으로 스크린샷 찍어두세요!

---

### Q6: 학교 수업을 안 들었는데 어떻게 하나요? (100일)
**A**: 괜찮아요!
- 평일에 수업 없으면 기록 안 해도 됨
- 자기주도 학습만 진행하세요
- 주말엔 자동으로 수업 기록 숨김

**💡 유연성**: 자기 상황에 맞춰 사용하세요!

---

### Q7: 복습을 깜빡했어요!
**A**: 괜찮아요, 다음날 해도 돼요.
- 누적 복습은 권장 날짜일 뿐
- 늦게라도 하는 게 안 하는 것보다 100배 나아요
- 완료 체크만 누르면 됩니다

**💡 리마인더**: 핸드폰 알람 설정 추천!

---

### Q8: AI 피드백이 정확한가요?
**A**: 데이터 기반 분석이에요.
- 학습 시간, 과목 수, 순서 등 객관적 데이터
- 자기점검 응답 반영
- 교육학 연구 기반 알고리즘

**💡 활용**: 100% 맹신보다는 참고 자료로!

• 사회: +2점 (40% → 60%)
