## 🚀 사용 방법

### 학생용
1. **링크 접속**: `https://da-um3481.github.io/da-um-jinro/geunhwa-student-portal.html`
2. **이름 입력**: 예) "김민준"
3. **찾기 버튼 클릭** 또는 **Enter 키**
4. **학습 시작**: 과목 선택 → 타이머 시작
5. **기록 저장**: 학습 완료 후 저장 버튼
6. **30일 스케줄 확인**: 우측 상단 버튼 클릭

### 선생님용
1. **학생 등록**: `students.html`에서 학생 정보 등록
2. **학습 기록 확인**: `student-study-records.html`
3. **주간 피드백 작성**: 학생 선택 → 피드백 입력
4. **4주 리포트 생성**: 자동 생성 버튼 클릭
5. **리포트 출력**: 인쇄/PDF 다운로드

### 학부모용
1. **포털 접속**: `parent-portal.html`
2. **자녀 이름 입력**: 예) "김민준"
3. **학습 현황 확인**: 시간, 진도, 피드백 열람
