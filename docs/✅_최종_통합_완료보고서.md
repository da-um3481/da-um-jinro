## 📊 기술 스택 및 구현 상세

### 프론트엔드 기술
- **HTML5**: 시맨틱 마크업
- **Tailwind CSS**: 반응형 디자인 및 유틸리티 클래스
- **JavaScript (Vanilla)**: 동적 기능 구현
- **Chart.js**: 모의고사 성적 추이 시각화
- **Font Awesome**: 아이콘 시스템

### 핵심 구현 기술

#### 1. URL 파라미터 기반 동적 렌더링
```javascript
const urlParams = new URLSearchParams(window.location.search);
const level = urlParams.get('level') || 'all';

if (level === 'high') {
    // 고등학생 전용 메뉴 표시
    document.getElementById('mockExamMenu').style.display = 'block';
    document.getElementById('semesterGradesMenu').style.display = 'block';
    document.getElementById('admissionMenu').style.display = 'block';
    document.getElementById('curriculumMenu').style.display = 'block';
} else if (level === 'middle') {
    // 중학생용 메뉴만 표시 (고등 전용 메뉴 숨김)
    document.getElementById('mockExamMenu').style.display = 'none';
    document.getElementById('semesterGradesMenu').style.display = 'none';
    document.getElementById('admissionMenu').style.display = 'none';
    document.getElementById('curriculumMenu').style.display = 'none';
}
```

#### 2. 등급 자동 계산 알고리즘
```javascript
function calculateGrade(average) {
    if (average >= 90) return 1;
    else if (average >= 80) return 2;
    else if (average >= 70) return 3;
    else if (average >= 60) return 4;
    else if (average >= 50) return 5;
    else if (average >= 40) return 6;
    else if (average >= 30) return 7;
    else if (average >= 20) return 8;
    else return 9;
}
```

#### 3. Chart.js 성적 추이 시각화
- 라인 차트 기반
- 과목별 색상 구분 (국어: 파랑, 수학: 빨강, 영어: 초록)
- 반응형 디자인
- 데이터 포인트 마커

#### 4. 등급별 색상 시스템
```javascript
function getGradeColor(grade) {
    const colors = {
        1: 'text-yellow-600',    // 금색
        2: 'text-gray-400',      // 은색
        3: 'text-orange-600',    // 동색
        4: 'text-blue-600',      // 파랑
        5: 'text-green-600',     // 초록
        6: 'text-purple-600',    // 보라
        7: 'text-pink-600',      // 분홍
        8: 'text-red-600',       // 빨강
        9: 'text-gray-600'       // 회색
    };
    return colors[grade] || 'text-gray-600';
}
```
