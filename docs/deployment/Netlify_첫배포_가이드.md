## 1️⃣ Build settings 섹션

### ✅ 확인할 항목:

```
Branch to deploy: main
```
→ ✅ 맞음! (GitHub의 main 브랜치 배포)

```
Build command: (비워두거나 다음 중 하나)
  - 비워두기 (권장)
  - echo 'Static site - no build needed'
```
→ ✅ 정적 사이트이므로 빌드 명령 불필요

```
Publish directory: .
```
→ ✅ **중요!** 점(.) 하나만 입력 (루트 디렉토리)

---

## 2️⃣ 설정 확인 후

화면 하단에 있는 버튼을 찾으세요:

```
[Save] 또는 [Deploy site]
```

이 버튼을 클릭하면 **첫 배포가 시작**됩니다!

---

## 3️⃣ 배포 진행 과정

버튼 클릭 후:

1. **🟡 Building...** (1~2분)
   - GitHub에서 코드 가져오기
   - 파일 처리 중
   
2. **🟢 Published!** (완료)
   - 사이트 URL 생성
   - 전 세계 접속 가능

배포 완료 후 사이트 이름을 변경할 수 있습니다:

```

```
