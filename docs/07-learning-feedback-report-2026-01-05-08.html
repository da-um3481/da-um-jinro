학생 피드백 샘플 (18명 전체)

📊 학습 현황

  • 학습 일수: 1일
  • 총 학습 기록: 1~4건
  • 학습 과목: 수학, 영어, 국어, 사회

💪 강점

  • 특정 과목 집중력
  • 균형 잡힌 학습 태도
  • 상세한 기록 작성

📈 개선 방향

  • 매일 꾸준한 학습 습관
  • 학습 기록 횟수 증가
  • 구체적인 내용 작성

🎯 다음 주 목표

  • 수학 과목 학습 시작
  • 영어 과목 학습 시작
  • 최소 3일 학습 기록

🎓 맞춤 학습 코칭 (5가지)

1. 💡 학습 습관 코칭

하루 최소 1회 학습 기록, 스마트폰 알람 활용, 30분씩 매일 기록

2. 📚 과목별 학습 전략

수학: EBS 강의→예제→문제 / 영어: 단어+문법+듣기 / 국어: 읽기→분석→정리

3. ⏰ 시간 관리 코칭

1주차: 하루 1시간 / 2주차: 하루 1시간 30분 / 50분 학습 + 10분 휴식

4. ✍️ 학습 기록 작성 코칭

구체적 내용 기록: 무엇을+어떻게+얼마나+어떤 느낌

5. 🎯 이번 주 실천 과제
[필수] 학습 기록 1회, 타이머 사용, 구체적 작성
[도전] 과목 시작, 단어 10개, 작품 1개 정독
[목표] 주 5일 기록, 하루 1.5시간, 상세 내용, 습관 형성

📢 전체 공지

✅ 잘하고 있는 점

  • 1월 5일 첫날 18명 전원 참여
  • 수학 중심 핵심 과목 집중
  • 상세한 학습 내용 기록

📌 개선이 필요한 부분

  • "학습 완료"만 기록하는 학생
  • 학습 시간 필드 대부분 비어있음

🎯 다음 주 전체 목표

  • 수학, 영어, 국어 골고루
