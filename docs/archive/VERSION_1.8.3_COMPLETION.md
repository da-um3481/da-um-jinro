## 🎨 모바일 최적화

### 반응형 디자인

**텍스트 크기:**
```css
/* 모바일 → 데스크톱 */
text-2xl → md:text-3xl  (헤더)
text-sm → md:text-base  (본문)
text-lg → md:text-xl    (부제)
```

**패딩/여백:**
```css
px-4 py-2 → md:px-6 md:py-3  (버튼)
py-8 → py-12  (섹션 간격)
```

**레이아웃:**
```css
/* 모바일: 1열, 데스크톱: 2열 */
grid md:grid-cols-2

/* 모바일: 세로 배치, 데스크톱: 가로 배치 */
flex-col md:flex-row
```

### 터치 최적화

**버튼 크기:**
```
최소 터치 영역: 44×44px 이상
실제 버튼: px-4 py-2 (더 큼)
```

**간격:**
```
카드 간격: space-y-6 (충분한 여백)
아이콘 간격: space-x-3 (터치 실수 방지)
```
