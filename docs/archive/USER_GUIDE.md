## 시스템 소개

### 프로그램 목적
중학교 방과후 학습을 체계적으로 관리하고, 학생들의 자기주도학습 능력을 향상시키기 위한 웹 기반 학습 관리 시스템입니다.

### 핵심 가치
- ⏰ **시간 관리**: 매일 3-4시간 학습 목표 달성
- 📊 **데이터 기반**: 객관적인 통계로 학습 현황 파악
- 🎯 **맞춤형 학습**: 학생 수준에 맞는 교재 및 계획
- 💬 **소통 강화**: 주간 피드백으로 지속적 개선

## 선생님 기능

### 1. 대시보드 (index.html)

#### 주요 통계 확인
- **전체 학생 수**: 등록된 학생 총원
- **주간 평균 달성률**: 이번 주 전체 학생 평균
- **오늘 학습 목표**: 오늘 완료해야 할 학습 수
- **피드백 대기**: 피드백 작성이 필요한 학생 수

#### 차트 분석
- **주간 학습시간 달성률**: 최근 4주간 추이
- **과목별 평균 학습시간**: 전체 학생 평균

#### 학생 현황 테이블
- 각 학생의 기본 정보, 평균 성적, 이번주 달성률 확인
- 상세보기, 피드백 버튼으로 빠른 접근

### 2. 학생 관리 (students.html)

#### 학생 등록
1. **기본 정보 입력**
   - 이름 (필수)
   - 학년/반/번호 (필수)
   
2. **성적 정보 입력**
   - 국어, 영어, 수학, 과학, 사회 점수
   - 입력 시 평균 자동 계산
   
3. **학습 수준 설정** (필수)
   - 상: 80점 이상
   - 중: 60-79점
   - 하: 60점 미만
   
4. **자동 교재 추천**
   - 저장 시 수준에 맞는 교재 자동 배정
   - 각 과목당 1개씩 추천

#### 학생 수정/삭제
- 수정: 연필 아이콘 클릭 → 정보 수정 → 저장
- 삭제: 휴지통 아이콘 클릭 → 확인
  - ⚠️ 주의: 관련된 모든 학습 데이터도 함께 삭제됩니다

### 3. 수업 관리 (lessons.html)

#### 수업 내용 등록
1. **날짜 선택** (기본값: 오늘)
2. **학년 선택** (1/2/3학년)
3. **과목 선택** (국어/영어/수학/과학/사회)
4. **단원/챕터 입력** (예: "2. 일차함수")
5. **중요도 설정**
   - 높음: 시험 출제 가능성 높음 → 학습 시간 자동 증가
   - 보통: 기본 학습
   - 낮음: 참고 학습
6. **수업 내용 상세 입력**

#### 효과
- 학생의 자동 학습 계획에 반영
- 복습 중심 학습 유도
- 중요 과목 집중 학습

#### 조회 및 관리
- 날짜별 검색
- 학년별/과목별 필터링
- 수정/삭제 가능

### 4. 피드백 작성 (feedback.html)

#### 주간 데이터 분석
1. **학생 선택**
2. **주간 설정** (기본값: 이번 주)
3. **"주간 데이터 불러오기"** 클릭

#### 자동 생성 정보
- 전체 계획 시간 vs 실제 시간
- 시간 달성률 (자동 계산)
- 과목별 학습 현황
- 주별 학습시간 차트
- 과목별 달성률 레이더 차트

#### 피드백 작성
1. **과목별 진도 입력**
   ```
   예시:
   국어: 문학 작품 분석 3편 완료
   수학: 일차함수 문제풀이 150문항
   ```

2. **개선사항 작성** (필수)
   ```
   예시:
   - 영어 듣기 시간을 늘릴 필요가 있음
   - 복습 시간을 매일 30분씩 확보
   ```

3. **종합 코멘트 작성** (필수)
   ```
   예시:
   이번 주 학습 태도가 매우 좋았습니다.
   특히 수학에서 많은 발전이 있었고,
   계획한 시간을 거의 완벽히 지켰습니다.
   ```

#### 작성 팁
- ✅ 구체적인 숫자 사용 ("150문항" vs "많이")
- ✅ 긍정적 표현 ("발전했습니다" vs "부족합니다")
- ✅ 실행 가능한 제안 ("30분씩" vs "더 많이")

### 5. 담임 보고서 (report.html)

#### 보고서 생성
1. **학생 선택**
2. **기간 설정** (기본값: 3월~4월)
3. **"보고서 생성"** 클릭

#### 보고서 구성
1. **학생 기본 정보**
   - 이름, 학년/반/번호, 수준, 평균 성적

2. **학습 시간 통계**
   - 전체 계획/실제 시간
   - 달성률, 완료 학습 수
   - 학습 일수, 일평균 시간
   - 주별 학습시간 차트

3. **과목별 성취도**
   - 레이더 차트로 시각화
   - 각 과목별 달성률

4. **주간 피드백 이력**
   - 모든 피드백 이력 표시
   - 주차별 달성률 표시

5. **종합 의견**
   - 학습 성과 요약
   - 자동 생성된 종합 평가
   - 향후 권장사항

#### 보고서 출력
1. **"인쇄"** 버튼 클릭
2. 프린터 선택 또는 "PDF로 저장"
3. 인쇄 설정 확인 후 출력

## 학생 기능

### 학생 포털 (student-portal.html)

#### 접속 및 로그인
1. `student-portal.html` 페이지 접속
2. 드롭다운에서 본인 이름 선택
3. 자동으로 오늘의 데이터 로드

#### 화면 구성

##### 1. 상단 정보
- 본인 정보 (이름, 학년, 반, 번호, 수준)
- 오늘 날짜
- 오늘의 목표 (4시간)

##### 2. 학습 현황 카드
- **오늘의 학습시간**: 현재까지 완료한 시간
- **완료한 과목**: 체크 완료한 과목 수 / 전체 5과목
- **이번주 달성률**: 주간 평균 달성률

##### 3. 오늘의 체크리스트
각 과목별 학습 항목:
- 과목 이름 (국어/영어/수학/과학/사회)
- 학습 내용
- 목표 시간
- 완료 체크박스
- "완료 체크" 버튼

##### 4. 추천 교재 및 강의
- 선생님이 추천한 교재 목록
- 교재 설명, 난이도
- 진도율 표시
- 바로가기 링크 (EBS 강의)

##### 5. 선생님 피드백
- 최근 3개 주간 피드백
- 달성률 및 선생님 코멘트
- 개선사항 확인

#### 학습 체크 방법

##### 방법 1: 간단 체크
1. 체크박스 클릭
2. 실제 학습 시간 입력
3. "완료 체크" 클릭

##### 방법 2: 상세 체크
1. "완료 체크" 버튼 클릭
2. 실제 학습 시간 입력
3. 메모 작성 (선택)
   ```
   예시:
   - 개념은 이해했는데 문제풀이가 어려워요
   - 복습이 필요할 것 같아요
   - 이해가 잘 되었어요!
   ```
4. "완료 체크" 클릭

#### 학습 팁
- 📱 **매일 접속**: 아침에 체크리스트 확인
- ⏰ **정해진 시간**: 매일 같은 시간에 학습
- ✅ **즉시 체크**: 학습 완료 후 바로 체크
- 💭 **메모 활용**: 어려운 점, 궁금한 점 기록
- 📊 **진도 확인**: 진행률 바 보면서 동기부여

## 자주 묻는 질문

### 선생님 FAQ

**Q: 학생 등록 후 체크리스트가 자동으로 생성되나요?**
A: 네, 학교 수업 내용을 등록하면 자동으로 생성됩니다. 수업 내용이 없으면 기본 4시간 계획으로 생성됩니다.

**Q: 교재를 추가하거나 변경할 수 있나요?**
A: 현재는 22개의 사전 등록된 교재가 있으며, 추가 등록은 개발자에게 문의하세요.

**Q: 과거 데이터를 수정할 수 있나요?**
A: 네, 피드백은 수정 가능하지만 일일 체크는 학생이 입력한 후에는 수정이 제한됩니다.

**Q: 한 학생에게 여러 교재를 추천할 수 있나요?**
A: 네, 학생 관리 페이지에서 수동으로 추가 배정이 가능합니다.

**Q: 보고서를 엑셀로 내보낼 수 있나요?**
A: 현재는 PDF 인쇄만 지원합니다. 엑셀 내보내기는 향후 추가 예정입니다.

### 학생 FAQ

**Q: 비밀번호가 있나요?**
A: 현재 버전은 간단한 선택 방식입니다. 향후 로그인 기능이 추가될 예정입니다.

**Q: 체크를 잘못했어요. 취소할 수 있나요?**
A: 완료 체크 후에는 취소가 어렵습니다. 선생님께 말씀드리세요.

**Q: 계획에 없는 공부를 했어요. 기록할 수 있나요?**
A: 메모란에 작성하시거나 선생님께 말씀드려 계획에 추가해 달라고 요청하세요.

**Q: 추천 교재는 꼭 사야 하나요?**
A: 아니요, 참고용입니다. EBS 무료 강의도 많이 있으니 활용하세요.

**Q: 4시간을 다 못했어요. 어떡하죠?**
A: 괜찮습니다. 실제로 공부한 시간을 정직하게 입력하세요. 선생님이 피드백을 주실 거예요.

### 기술 FAQ

**Q: 모바일에서도 사용할 수 있나요?**
A: 네, 반응형 디자인으로 제작되어 스마트폰, 태블릿에서도 사용 가능합니다.

**Q: 인터넷이 없어도 되나요?**
A: 아니요, 인터넷 연결이 필요합니다.

**Q: 데이터는 어디에 저장되나요?**
A: RESTful Table API를 통해 안전하게 저장됩니다.

**Q: 여러 선생님이 동시에 사용할 수 있나요?**
A: 네, 가능합니다.

## 💡 성공 비결

### 선생님을 위한 팁
1. **매일 수업 내용 등록** - 자동 계획 생성의 핵심
