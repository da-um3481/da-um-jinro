## 💻 주요 기능 코드

### JavaScript 함수

#### 1. 학생 선택 함수
```javascript
function loadStudentFeedback() {  // 또는 loadStudentReport(), loadStudentSchedule()
    const name = document.getElementById('studentNameInput').value.trim();
    if (!name) {
        alert('학생 이름을 입력해주세요.');
        return;
    }
    
    // 선택된 학생 표시
    document.getElementById('selectedStudent').classList.remove('hidden');
    document.getElementById('studentNameDisplay').textContent = name;
    
    // localStorage에 저장
    localStorage.setItem('winter_selected_student', name);
    
    // 성공 메시지
    showToast(`${name} 학생의 [피드백/보고서/일정]을 조회합니다.`);
}
```

#### 2. 토스트 알림
```javascript
function showToast(message) {
    const toast = document.createElement('div');
    toast.className = 'fixed top-20 right-6 bg-white rounded-xl shadow-2xl p-4 flex items-center space-x-3 border-l-4 border-cyan-500 z-50';
    toast.innerHTML = `
        <i class="fas fa-check-circle text-cyan-500 text-2xl"></i>
        <span class="font-bold text-gray-800">${message}</span>
    `;
    document.body.appendChild(toast);
    
    setTimeout(() => {
        toast.remove();
    }, 3000);
}
```

#### 3. 자동 복원 (페이지 로드 시)
```javascript
window.addEventListener('load', function() {
    const savedStudent = localStorage.getItem('winter_selected_student');
    if (savedStudent) {
        document.getElementById('studentNameInput').value = savedStudent;
        document.getElementById('selectedStudent').classList.remove('hidden');
        document.getElementById('studentNameDisplay').textContent = savedStudent;
    }
});
```
