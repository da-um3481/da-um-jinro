## 🔧 기술 구현

### 파일 구조
```
/home/user/webapp/
├── js/
│   └── security.js          ← 통합 보안 스크립트 (새로 생성)
├── index.html               ← 보안 스크립트 추가
├── teacher-dashboard.html   ← 보안 스크립트 추가
├── students.html            ← 보안 스크립트 추가
└── ... (기타 8개 페이지)
```

### 보안 스크립트 통합
```html
<!-- 모든 보호 페이지의 <head> 섹션에 추가 -->
<script src="js/security.js"></script>
```

### 핵심 기술
- **IIFE (즉시 실행 함수)**: 전역 오염 방지
- **SessionStorage**: 인증 상태 유지
- **MutationObserver**: 워터마크 보호
- **Event Listeners**: 사용자 동작 감지
- **Console Styling**: 경고 메시지 시각화
