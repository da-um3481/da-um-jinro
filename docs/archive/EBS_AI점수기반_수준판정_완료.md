## 💻 JavaScript 핵심 기능

### 1. **자동 수준 계산 함수**

```javascript
function calculateLevel() {
    const score = parseInt(document.getElementById('ebsScoreInput').value);
    
    if (score <= 59) {
        level = 'basic';           // 기초
        levelText = '기초 (0-59점)';
    } else if (score <= 74) {
        level = 'lower_intermediate';  // 중하
        levelText = '중하 (60-74점)';
    } else if (score <= 89) {
        level = 'upper_intermediate';  // 중상
        levelText = '중상 (75-89점)';
    } else {
        level = 'advanced';        // 상급
        levelText = '상급 (90-100점)';
    }
    
    return level;
}
```

**실시간 계산:**
- `oninput` 이벤트로 즉시 계산
- 0-100 범위 검증
- 자동 판정 결과 표시

## 📈 점수 구간별 학습 전략

### 📚 **기초 (0-59점)**

**현재 상태:**
- 기본 개념이 부족
- 학습 습관 미형성
- 문제 풀이 어려움

**학습 전략:**
1. **Week 1-2**: 천천히 시작 (하루 2-3시간부터)
2. 쉬운 교재 선택 (체크체크)
3. EBS AI 코스웨어 매일 30분
4. 개념 이해 중심 학습

**기대 효과:**
- 30일 후 중하(60점) 수준 도달
- 기본 개념 완전 이해
- 학습 습관 완성

---

### 📖 **중하 (60-74점)**

**현재 상태:**
- 기본 개념 이해 중
- 학습 습관 불규칙
- 응용 문제 어려움

**학습 전략:**
1. **Week 1-2**: 규칙적인 루틴 확립 (하루 4시간)
2. 표준 교재 선택 (개념원리)
3. 오답 노트 작성 시작
4. 개념 + 유형 학습

**기대 효과:**
- 30일 후 중상(75점) 수준 도달
- 내신 대비 가능
- 안정적 학습 패턴

---

### 🚀 **중상 (75-89점)**

**현재 상태:**
- 개념 이해 우수
- 학습 습관 형성
- 심화 문제 도전 가능

**학습 전략:**
1. **Week 1**: 빠른 루틴 확립 (3일)
2. 심화 교재 선택 (일품)
3. 선행학습 병행 (Week 3)
4. 고난도 문제 풀이

**기대 효과:**
- 30일 후 상급(90점) 수준 도달
- 새학기 선행학습 완료
- 최상위권 도약

---

### ⭐ **상급 (90-100점)**

**현재 상태:**
- 개념 완벽 이해
- 학습 습관 확고
- 경시 대회 가능

**학습 전략:**
1. **Week 1**: 즉시 4시간 달성
2. 최고난도 교재 (블랙라벨)
3. 선행학습 + 심화학습
4. 대회 문제 풀이

**기대 효과:**
- 30일 후 최상위 유지
- 고등 수준 도달
- 자신감 극대화
