✅ 2교시 - 영어 (완료)
   - 시간: 18:15-19:15 (60분)
   - 교재: 내신대비 문법 중2 (Unit 4)
   - 강의: EBS 중학 - 관계대명사
   - 성과: 16/18 정답 (88%)
```

```

   - 교재: 중학 수학 2-1 (일차함수)
   - 강의: EBS 중학 - 일차함수의 그래프
   - 진행: 35/70분 (50%)

⏰ 4교시 - 과학 (예정)
   - 시간: 20:50-21:40 (50분)
   - 교재: 중2 과학 (p.64-80)
   - 강의: EBS 중학 - 물질의 특성
   - 예정: 15문제
```

⏱️ 학습 시간: 120분
📈 정답률: 89%
```
