**1단계: 학습 전**
```
상태 표시: 🔘 빈 원 아이콘
버튼: [▶️ 시작] (과목별 색상)
정보: 목표 시간만 표시
```

**2단계: 학습 중**
```
상태 표시: ⏳ 모래시계 아이콘 (주황색)
타이머: 실시간 표시 (예: 00:15, 01:30, 1:05:30)
정보: 
  - 목표: 60분
  - 시작: 14:30 (시작 시각 표시)
버튼: [⏹️ 완료] (빨간색)
```

**3단계: 학습 완료**
```
상태 표시: ✅ 체크 원 아이콘 (초록색)
정보:
  - 목표: 60분
  - 완료: 45분 (자동 계산된 실제 시간)
  - 종료: 15:15 (종료 시각 표시)
표시: [✓ 완료] (초록색 배지)
```

#### 🔧 기술적 구현

**데이터베이스 필드 (daily_checks)**
```javascript
{
  id: "uuid",
  student_id: "student-uuid",
  subject: "수학",
  content: "1차 함수 복습",
  planned_time: 60,           // 계획된 시간 (분)
  start_time: "2025-12-07T14:30:00.000Z",  // 시작 시간 (ISO 8601)
  end_time: "2025-12-07T15:15:00.000Z",    // 종료 시간 (ISO 8601)
  actual_time: 45,            // 실제 학습 시간 (분, 자동 계산)
  completed: true,            // 완료 여부
  memo: "45분 학습 완료"      // 자동 생성 메모
}
```

**자동 계산 로직**
```javascript
// 학습 시작
start_time = new Date().toISOString()  // 현재 시각 기록
타이머 시작 (1초마다 업데이트)

// 학습 완료
end_time = new Date().toISOString()    // 종료 시각 기록
actual_time = Math.round((end_time - start_time) / 1000 / 60)  // 분 단위 계산
completed = true
memo = `${actual_time}분 학습 완료`
```
