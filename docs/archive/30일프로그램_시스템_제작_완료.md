## ✅ 완료된 시스템 (6개 페이지)

- 30일 프로그램 전체 진행률 실시간 모니터링

- 교과별 학습 시간 분포 파이 차트
- 오늘의 학습 현황 (5개 과목 진행률)
- 최근 학습 활동 타임라인

**기술:**
- Tailwind CSS + Chart.js
- 눈송이 애니메이션 (15개)

- 30일 프로그램 진행률 개인 대시보드

- 오늘의 총 학습 시간 및 달성률 계산
- 나의 교재 진도 관리 (3개 교재 진도율 표시)
- 주간 학습 통계 (7일 캘린더, 출석 체크)

**특징:**
- 과목별 색상 구분 (Blue/Green/Red/Purple/Yellow)
- 실시간 타이머 (MM:SS 형식)

  - 📘 기초: Grammar Zone 기초편 (⭐⭐)
  - 📗 내신: 천재 자습서 + 리딩튜터 (⭐⭐⭐)
  - 📕 최상위: 리딩파워/능률보카 (⭐⭐⭐⭐⭐)
- 국어, 과학, 사회 교재 추천
- EBS 무료 강의 링크 (2개)

**특징:**
- 난이도 별 표시 (⭐⭐⭐⭐⭐)

## 🚀 사용 방법

### 관리자 (선생님/컨설턴트)
1. **대시보드 확인**: `winter-index.html` 열기
2. **주간 계획 확인**: `winter-weekly-schedule.html`
3. **피드백 작성**: `winter-feedback.html`
4. **보고서 생성**: `winter-report.html`

### 학생
1. **학습 포털 접속**: `winter-student-portal.html`
2. **이름 입력**: 본인 이름 입력 후 "찾기" 클릭
3. **학습 시작**: 과목별 "시작" 버튼 클릭
4. **학습 완료**: 학습 종료 후 "완료" 버튼 클릭
5. **교재 확인**: `winter-materials.html`에서 추천 교재 확인
6. **일정 확인**: `winter-weekly-schedule.html`에서 주간 계획 확인
