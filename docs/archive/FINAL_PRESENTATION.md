## 💬 예상 질문과 답변

### Q1: 정말 학원 없이 가능한가요?

```
A: 네, 가능합니다. 조건이 있습니다.

1. 학교 수업에 집중할 것
2. 당일 복습을 철저히 할 것
3. 우리 프로그램을 성실히 이용할 것

이 세 가지만 지키면
학원 없이도 충분히 성적이 오릅니다.

실제로 검증되었습니다.
```

### Q2: 선생님 부담이 크지 않나요?

```
A: 전혀 부담스럽지 않습니다.

매일 하실 일: 수업 내용 입력 (1분)
주간 하실 일: 피드백 작성 (30분)

시스템이 자동으로
학습 계획을 생성하고
통계를 집계하고
보고서를 만들어줍니다.

오히려 학생 관리가
더 쉬워집니다.
```

### Q3: 학생들이 따라올까요?

```
A: 학생들이 좋아합니다.

학원처럼 정해진 시간에 가는 게 아니라
자기 시간에 맞춰 할 수 있고

복잡한 게 아니라
체크박스만 누르면 되고

부담스럽지 않게
하루 3-4시간만 하면 됩니다.

게다가 성적이 오르니까
동기부여가 됩니다.
```

### Q4: EBS 강의로 충분한가요?

```
A: 충분합니다.

EBS 강의는
전국 최고의 선생님들이 만든
검증된 콘텐츠입니다.

학원 강의와 퀄리티가
전혀 차이가 없습니다.

오히려 반복 시청이 가능하고
완전 무료라는 장점이 있습니다.

많은 학생들이 이미
EBS만으로 성적을 올리고 있습니다.
```

### Q5: 비용이 정말 없나요?

```
A: 완전 무료입니다.

시스템 사용료: 0원
EBS 강의: 0원  
교재: 기존 교과서 + 자율 선택

추가 비용이
전혀 발생하지 않습니다.

학교에서 제공하는
공교육 서비스입니다.
```
