## 🎯 업데이트 개요

대시보드 페이지에서 **직접 학생 정보를 등록**할 수 있는 "빠른 학생 등록" 섹션을 추가했습니다. 이제 별도의 학생 관리 페이지로 이동하지 않고도 대시보드에서 바로 학생을 등록할 수 있습니다.

---

## ✨ 새로운 기능

### 1️⃣ 빠른 학생 등록 섹션

대시보드 상단 통계 카드 바로 아래에 학생 등록 폼이 추가되었습니다.

## 🆕 주요 기능

### 1. **한 화면에서 모든 작업 완료**
- ✅ 기본 정보 입력 (이름, 학년, 반, 번호)
- ✅ EBS AI 진단평가 점수 입력 (5과목)
- ✅ 자동 수준 판정
- ✅ 즉시 등록 및 대시보드 갱신

### 2. **실시간 자동 수준 판정**
- 점수 입력 시 자동으로 평균 계산
- 수준 자동 판정 (기초/중하/중상/상급)
- 시각적 피드백 (배경색 변경)

### 3. **교재 자동 추천**
- 학생 등록 시 수준에 맞는 교재 자동 배정
- 5과목 각 1개씩 추천 교재 자동 등록

### 4. **즉시 반영**
- 등록 후 1초 내 대시보드 자동 갱신
- 학생 목록에 즉시 표시
- 성공 메시지로 확인

#### 2. 학생 등록 처리
```javascript
async function handleQuickStudentSubmit(e) {
    e.preventDefault();
    
    // 자동 수준 판정
    autoCalculateLevelQuick();
    
    const level = document.getElementById('quickLevel').value;
    if (!level) {

    const studentData = {

        english_score: parseFloat(document.getElementById('quickEnglish').value) || 0,
        math_score: parseFloat(document.getElementById('quickMath').value) || 0,
        science_score: parseFloat(document.getElementById('quickScience').value) || 0,
        social_score: parseFloat(document.getElementById('quickSocial').value) || 0,
        level: level,
        status: '활동중',
        school_id: selectedSchoolId || null
    };
    
    // 학생 등록 API 호출
    const response = await fetch('tables/students', {
```

#### 3. 자동 수준 계산
```javascript
function autoCalculateLevelQuick() {
    const korean = parseFloat(document.getElementById('quickKorean').value) || 0;
    const english = parseFloat(document.getElementById('quickEnglish').value) || 0;
    const math = parseFloat(document.getElementById('quickMath').value) || 0;
    const science = parseFloat(document.getElementById('quickScience').value) || 0;
    const social = parseFloat(document.getElementById('quickSocial').value) || 0;
    
    const scores = [korean, english, math, science, social].filter(s => s > 0);
    
    if (scores.length === 0) {
        document.getElementById('quickLevel').value = '';
        document.getElementById('quickLevel').disabled = true;
        return;
    }
    
    const avgScore = scores.reduce((a, b) => a + b, 0) / scores.length;
    let level = '';
    
    if (avgScore >= 85) level = '상급';
    else if (avgScore >= 70) level = '중상';
    else if (avgScore >= 50) level = '중하';
    else level = '기초';
    
    const levelSelect = document.getElementById('quickLevel');
    levelSelect.value = level;
    levelSelect.disabled = false;
    
    // 배경색 시각적 피드백
    const colors = {
        '기초': '#dcfce7',
        '중하': '#dbeafe',
        '중상': '#fef3c7',
        '상급': '#fee2e2'
    };
    levelSelect.style.backgroundColor = colors[level];
    levelSelect.style.fontWeight = 'bold';
}
```

#### 4. 교재 자동 추천
```javascript
async function recommendMaterialsQuick(studentId, level) {
    const response = await fetch('tables/materials?limit=100');
    const data = await response.json();
    
    const recommendedMaterials = data.data.filter(m => m.level === level);
    const subjects = ['국어', '영어', '수학', '과학', '사회'];
    
    for (const subject of subjects) {
        const material = recommendedMaterials.find(m => m.subject === subject);
        if (material) {
            await fetch('tables/student_materials', {
                method: 'POST',
                headers: {'Content-Type': 'application/json'},
                body: JSON.stringify({
                    student_id: studentId,
                    material_id: material.id,
                    assigned_date: new Date().toISOString().split('T')[0],
                    status: '진행중',
                    progress: 0
                })
            });
        }
    }
}
```

## 📋 사용 방법

### 선생님용 (대시보드에서 학생 등록)

1. **대시보드 접속**
   - `index.html` 페이지 열기
   - 상단 통계 카드 아래 "빠른 학생 등록" 섹션 확인

2. **기본 정보 입력**
   ```
   이름: 홍길동
   학년: 2학년
   반: 3
   번호: 15
   ```

3. **EBS AI 진단평가 점수 입력** (선택)
   ```
   국어: 75
   영어: 82
   수학: 68
   과학: 71
   사회: 79
   ```
   - 점수 입력 시 자동으로 평균 계산 (75점)
   - 수준 자동 판정: "🟡 중상 (70-84점)"
   - 배경색 노란색으로 변경

4. **학생 등록 버튼 클릭**
   - 성공 메시지 표시: "✅ 홍길동 학생이 성공적으로 등록되었습니다!"
   - 폼 자동 초기화
   - 1초 후 대시보드 자동 갱신
   - 학생 목록에 새 학생 표시
   - 수준별 교재 자동 추천 완료

5. **전체 학생 목록 확인**
   - 우측 상단 "전체 학생 목록" 버튼 클릭
   - `students.html` 페이지로 이동
   - 상세 정보 확인 및 수정 가능
