## 📊 EBS 학습 생태계 구조 분석

### 1️⃣ EBS 중학 프리미엄 (mid.ebs.co.kr)
**대표 온라인 강의 플랫폼**

#### 🎓 수준별 강좌 체계
| 수준 | 대상 학생 | 특징 | 대표 시리즈 |
|------|----------|------|-------------|
| **쌩기초** | 기초 개념 습득 필요 | 천천히, 반복적으로 설명 | 쌩기초 개념 시리즈 |
| **기초** | 개념 이해 부족 | 기본 개념부터 체계적 학습 | EBS 기초 교재, 기초 탄탄 |
| **기본** | 표준 학습자 | 교과서 중심 개념+응용 | 중학 뉴런, 포텐 |
| **발전** | 심화 학습 희망 | 응용력 강화, 고난도 문제 | 뉴런 심화, 올리드 |

#### 📚 주요 교재 시리즈

##### A. **EBS 중학 뉴런** (표준~발전)
- **구성**: 개념책 + 실전책 + 미니북
- **특징**: 
  - 전 과목 모든 교과서 통합 자기주도 학습 기본서
  - 개념 다지기 → 실력 쌓기 → 대단원 마무리 → 수행평가
  - 중급~고급 수준
- **과목**: 국어, 수학, 영어, 사회, 역사, 과학
- **강의**: 20일 완성 단기특강 또는 정규 강좌
- **추천 대상**: 평균 60~85점 학생 (중급~심화)

##### B. **EBS 기초 교재** (기초~기본)
- **구성**: 단원별 핵심 정리 + 기본 문제 + 응용 문제
- **특징**:
  - 교과서 중심 기본+응용 문제집
  - 학교 시험 대비 최적화
  - 단원평가 100점 목표
- **과목**: 국어, 수학, 영어, 사회, 과학 (학기별 통합)
- **추천 대상**: 평균 40~70점 학생 (기초~중급)

##### C. **수학 마스터** (수준별 3단계)
- **α(알파)**: 기초 연산 강화
- **β(베타)**: 유형별 문제 정복
- **γ(감마)**: 심화 문제 해결

##### D. **필독** (국어 특화)
- 28일로 완성하는 수능까지 잡는 중학 국어
- 문법, 문학 1·2·3, 비문학 독해 1·2·3 구성

##### E. **포텐** (사회 특화)
- 사회 교과서 내용 완벽 정리
- 개념 이해 + 문제 적용력 강화

#### 🎬 강의 유형
1. **교과서 강의**: 출판사별 교과서 완벽 대응
2. **교재 강의**: EBS 교재 및 시중 교재 연계
3. **특강**: 기말/중간고사, 단기 완성
4. **수준별 맞춤**: 쌩기초 → 기초 → 기본 → 발전

### 2️⃣ EBS AI 코스웨어 (단추) (https://ai-plus.ebs.co.kr/onestop/mid/main_mid.ebs)
**AI 기반 개인 맞춤형 학습 플랫폼 - 딥러닝 알고리즘 활용**

#### 🤖 핵심 기능

##### 1. **AI 진단 시스템**
```
자가진단 → AI 분석 → 수준 판정 → 맞춤 학습 경로 제공
```

- **진단 평가**: 학생의 현재 실력 정확히 측정
- **딥러닝 분석**: 문제 풀이 이력 실시간 분석
- **취약점 도출**: 부족한 개념/영역 자동 추출

##### 2. **4단계 학습 루틴**

| 단계 | 내용 | 기능 |
|------|------|------|
| **STEP 1: 진단** | AI 학습 진단 | 효율적인 자기주도학습 실현을 위한 현재 수준 파악 |
| **STEP 2: 개념학습** | 맞춤형 개념 강의 | 부족한 개념을 집중적으로 학습 |
| **STEP 3: 심화학습** | 응용력 강화 | 개념을 바탕으로 문제 해결력 향상 |
| **STEP 4: 최종평가** | 학습 완성도 점검 | 학습 성과 확인 및 재진단 |

##### 3. **맞춤형 문제 추천**
- **딥러닝 알고리즘**: 문제 풀이 패턴 분석
- **최적화된 학습 경로**: 학생별 맞춤 문제 자동 제공
- **적응형 난이도**: 실력 향상에 따라 문제 난이도 자동 조절

##### 4. **학습 분석 리포트**
- 과목별/단원별 성취도
- 학습 시간 통계
- 취약 영역 분석
- 학습 추천 사항

#### 📱 단추+ (단과 학습관)
- **과목별 집중 학습**: 특정 과목만 선택 학습 가능
- **단원별 학습**: 필요한 단원만 골라 학습
- **AI 푸리봇**: 학습 도우미 챗봇 (질문/추천/가이드)

**구현 방법**:
1. 학생별 EBS AI 코스웨어 진단 페이지 직접 링크 제공
2. 학생이 EBS에서 진단 평가 완료
3. 결과를 DA.UM 시스템에 수동/자동 입력
4. 실시간 수준별 콘텐츠 자동 업데이트

#### A. 교재 추천 시스템
```javascript
function recommendTextbooks(subject, score) {
    if (score < 50) {
        return {
            primary: 'EBS 기초 ' + subject,
            secondary: '쌩기초 개념 ' + subject,
            link: 'https://mid.ebs.co.kr/book/...'

            secondary: '포텐/올리드 ' + subject,

            secondary: '수능특강 ' + subject,
            link: 'https://mid.ebs.co.kr/book/...'
        };
    }
}
```

## 📋 결론

**EBS 중학 프리미엄**과 **EBS AI 코스웨어(단추)**는 각각:
- **중학 프리미엄**: 수준별 강의 + 교재 중심
- **AI 코스웨어**: AI 진단 + 맞춤형 학습 경로

두 시스템을 **DA.UM 맞춤형 학습**과 통합하면:
1. 학생의 **정확한 수준 진단** (AI 코스웨어)
2. 수준에 맞는 **최적의 교재와 강의** 추천 (중학 프리미엄)
3. **개인화된 주간 학습 플랜** 자동 생성 (DA.UM)
4. **학습 성과 실시간 추적** (통합 대시보드)
