## 🆕 주요 기능

### 1. 빠른 학생 등록

#### 기능
- ✅ 기본 정보 입력 (이름, 학년, 반, 번호)
- ✅ EBS AI 진단평가 점수 입력 (5과목)
- ✅ 자동 수준 판정 (기초/중하/중상/상급)
- ✅ 실시간 시각적 피드백 (배경색 변경)
- ✅ 성공 메시지 표시
- ✅ 페이지 자동 새로고침

#### JavaScript 기능
```javascript
// 1. 폼 제출 이벤트
quickForm.addEventListener('submit', handleQuickStudentSubmit);

// 2. 점수 입력 시 자동 수준 판정
scoreInputs.forEach(inputId => {
    input.addEventListener('input', autoCalculateLevelQuick);
});

// 3. 자동 수준 계산 알고리즘
function autoCalculateLevelQuick() {
    const avgScore = scores.reduce((a, b) => a + b) / scores.length;
    let level = avgScore >= 85 ? '상급' : 
                avgScore >= 70 ? '중상' : 
                avgScore >= 50 ? '중하' : '기초';
}

// 4. 학생 등록 API 호출
await fetch('tables/students', {
    method: 'POST',
    headers: {'Content-Type': 'application/json'},
    body: JSON.stringify(studentData)
});

// 5. 성공 메시지 표시
showSuccessMessage('✅ 홍길동 학생이 성공적으로 등록되었습니다!');
```
