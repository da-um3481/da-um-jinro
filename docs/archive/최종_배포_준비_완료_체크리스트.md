## 🚀 3. Netlify 배포 설정

### ✅ netlify.toml 설정 완료
```toml
[build]
  publish = "."
  command = "echo 'Static site - no build needed'"

[[redirects]]
  from = "/"
  to = "/winter-index.html"
  status = 200

[[headers]]
  for = "/*"
  [headers.values]
    X-Frame-Options = "DENY"
    X-Content-Type-Options = "nosniff"
    X-XSS-Protection = "1; mode=block"
```

### ✅ 배포 설정 특징
- **정적 사이트**: 빌드 과정 불필요
- **메인 페이지**: 자동으로 `winter-index.html`로 리다이렉트
- **보안 헤더**: XSS, iframe 공격 방지
- **HTTPS**: Netlify가 자동으로 SSL 인증서 발급
