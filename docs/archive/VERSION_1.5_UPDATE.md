# 📦 버전 1.5.0 업데이트 가이드

**버전**: 1.5.0  
**이전 버전**: 1.4.0

## 🌟 주요 변경사항

### ✨ 1. 학생 포털 자동 인식 기능

이제 학생 포털이 **요일을 자동으로 감지**하여 평일과 주말에 맞는 학습 계획을 제공합니다!

#### 평일 (월~금)
- **목표 시간**: 자동으로 **4시간 (240분)** 설정
- **학습 내용**: "학교수업 복습 + 교재 학습" 중심
- **시간 배분**:
  - 학교 수업 복습: 60분
  - 주요 과목 학습: 180분 (수학, 영어, 국어, 과학, 사회)
- **진행률 계산**: 240분 기준 자동 계산

#### 주말 (토~일)
- **목표 시간**: 자동으로 **6시간 (360분)** 설정
- **학습 내용**: "주간 총복습 + 단원별 문제풀이" 중심
- **시간 배분**:
  - 주간 총복습: 180분
  - 단원별 문제풀이: 120분
  - 오답 정리 및 다음 주 준비: 60분
- **진행률 계산**: 360분 기준 자동 계산

### 📊 2. 자동 학습 계획 생성 개선

학습 계획 생성 로직이 평일/주말을 자동으로 구분하여 최적화된 시간 배분을 제공합니다.

#### 평일 기본 시간 배분 (총 240분)
```
국어: 40분
영어: 40분
수학: 60분 ⭐ (가장 중요)
과학: 50분
사회: 50분
```

#### 주말 기본 시간 배분 (총 360분)
```
국어: 60분 (+20분)
영어: 60분 (+20분)
수학: 90분 (+30분) ⭐ (가장 중요)
과학: 75분 (+25분)
사회: 75분 (+25분)
```

## 📈 기대 효과

### 1. 학습 효율 향상
- ✅ 평일: 복습 중심으로 학교 수업 내용 완벽 이해
- ✅ 주말: 주간 학습 내용 총정리 및 문제풀이 강화

### 2. 시간 관리 최적화
- ✅ 평일 4시간 × 5일 = **20시간**
- ✅ 주말 6시간 × 2일 = **12시간**
- ✅ 주간 총 **32시간** 학습 달성

### 3. 학습 부담 완화
- ✅ 평일: 학교 수업 + 4시간 학습으로 무리 없는 학습량
- ✅ 주말: 여유 있는 시간으로 깊이 있는 복습 및 문제풀이

### 4. 자동화된 맞춤 학습
- ✅ 학생이 별도 설정 없이 포털 접속만으로 자동 적용
- ✅ 선생님의 수동 조정 작업 불필요

## 🚀 사용 방법

### 학생 입장

1. **평일 (월~금)에 학생 포털 접속**
   ```
   → 자동으로 "오늘의 목표: 4시간 (평일)" 표시
   → 체크리스트: "학교수업 복습 + 교재 학습" 내용
   → 진행률: 240분 기준으로 계산
   ```

2. **주말 (토~일)에 학생 포털 접속**
   ```
   → 자동으로 "오늘의 목표: 6시간 (주말)" 표시
   → 체크리스트: "주간 총복습 + 문제풀이" 내용
   → 진행률: 360분 기준으로 계산
   ```

3. **학습 진행**
   - 체크리스트에 표시된 과목을 순서대로 학습
   - 완료 후 체크박스 클릭
   - 실제 학습 시간 입력

### 선생님 입장

1. **추가 설정 불필요!**
   - 기존처럼 학교 수업 내용만 등록하면 자동으로 적용됩니다.

2. **대시보드에서 모니터링**
   - 평일: 학생들의 4시간 목표 달성률 확인
   - 주말: 학생들의 6시간 목표 달성률 확인

3. **주간 스케줄 활용**
   - `weekly-schedule.html`에서 학생별 평일/주말 상세 계획 확인 가능
