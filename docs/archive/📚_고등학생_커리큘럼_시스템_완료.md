## 📅 주간 학습 스케줄 (32시간)

### 평일 (월~금) - 하루 4시간 × 5일 = 20시간
```
월요일: 국어 2h + 영어 2h
화요일: 수학 2h + 탐구 2h
수요일: 국어 2h + 영어 2h
목요일: 수학 2h + 탐구 2h
금요일: 국어 2h + 영어 2h
```

### 주말 (토~일) - 하루 6시간 × 2일 = 12시간
```
토요일: 수학 집중 3h + 모의고사 풀이 3h
일요일: 주간 복습 3h + 약점 보완 3h
```

### 과목별 시간 배분
- **국어**: 8시간/주
- **영어**: 8시간/주
- **수학**: 10시간/주 (가장 중요)
- **탐구**: 6시간/주

## 📚 추천 교재 체계

### 국어
#### 상 (최상위권)
- 비문학 독서 고급
- 문학 심화 개념
- 문법 마스터
- **EBS**: 수능특강 국어영역, 수능완성 독서

#### 중 (중위권)
- 국어 필수 개념
- 독서 기본서
- 문법 기초
- **EBS**: EBS 기본서 국어, 올림포스 국어

#### 하 (기초반)
- 국어 기초 다지기
- 독서 쉬운 지문
- 맞춤법과 문법
- **EBS**: EBS 중학 국어 복습

### 영어
#### 상 (최상위권)
- 영어 구문독해 고급
- 수능 어휘 완성
- 영어 듣기 모의고사
- **EBS**: EBS 수능특강 영어, EBS 영어독해 연습

#### 중 (중위권)
- 영어 구문 기본
- 필수 영단어 3000
- 영어 듣기 기본
- **EBS**: EBS 영어영역 기본, 올림포스 영어

#### 하 (기초반)
- 영어 문법 기초
- 필수 영단어 1800
- 영어 듣기 입문
- **EBS**: EBS 영어 기초

### 수학
#### 상 (최상위권)
- 수학(상) 심화, 수학(하) 심화
- 수학I 심화, 수학II 심화
- 확률과 통계/미적분
- 1등급 수학 문제집
- **EBS**: EBS 수능특강 수학, 올림포스 고난도

#### 중 (중위권)
- 수학(상) 개념원리, 수학(하) 개념원리
- 수학I 개념+유형, 수학II 개념+유형
- 기본 문제집
- **EBS**: EBS 기본서 수학, 올림포스 수학

#### 하 (기초반)
- 수학 기초 개념서
- 중학 수학 총복습
- 수학I 기초, 수학II 기초
- **EBS**: EBS 기초 수학

### 탐구 (과학/사회)
#### 상 (최상위권)
- 선택 과목 심화 (물리/화학/생명/지구)
- 실전 모의고사
- 기출 분석
- **EBS**: 수능특강 과학탐구, 수능완성 과학탐구

#### 중 (중위권)
- 선택 과목 기본서
- 표준 문제집
- **EBS**: 올림포스 과학탐구

#### 하 (기초반)
- 선택 과목 기초서
- 통합과학 기본서
- **EBS**: EBS 과학 기초, EBS 통합과학
