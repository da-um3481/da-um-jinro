# DA.UM 겨울방학 30일 프로그램 시스템 가이드

## 📋 프로그램 개요

**DA.UM 겨울방학 30일 프로그램**은 중학생을 위한 자기주도학습 습관 형성 프로그램입니다.

### 핵심 목표
- 📚 일일 4시간 자기주도학습 습관 확립
- 🎯 30일간 총 120시간 학습 목표
- ❄️ 겨울방학 기간 집중 학습 (4주 완성)
- 📖 교재 중심 체계적 학습
- 🔥 새학기 준비 및 학습 습관 형성

---

## 🌐 시스템 구성

### 1. **winter-index.html** - 학습관리 대시보드 (관리자용)
**주요 기능:**
- 30일 프로그램 전체 진행률 실시간 모니터링
- 4주(Week 1~4) 진행 상황 시각화
- 총 학습 시간, 일일 평균, 출석률, 교재 진도 통계
- Chart.js 기반 일일 학습 시간 추이 차트
- 교과별 학습 시간 분포 파이 차트
- 오늘의 학습 현황 (5개 과목)
- 최근 학습 활동 타임라인

**기술 스택:**
- Tailwind CSS
- Chart.js (데이터 시각화)
- Font Awesome
- 눈송이 애니메이션 효과 (겨울 테마)

**URL:** `winter-index.html`

---

### 2. **winter-student-portal.html** - 학생 포털
**주요 기능:**
- 학생 이름으로 로그인
- 30일 프로그램 진행률 개인 대시보드
- 5개 과목별 실시간 타이머 (시작/완료 버튼)
  - 수학: 60분 목표
  - 영어: 60분 목표
  - 국어: 50분 목표
  - 과학: 40분 목표
  - 사회: 30분 목표
- 오늘의 총 학습 시간 및 달성률
- 나의 교재 진도 관리 (진도율 표시)
- 주간 학습 통계 (7일 캘린더)

**특징:**
- 모바일 최적화 반응형 디자인
- 과목별 색상 구분 (Blue, Green, Red, Purple, Yellow)
- 실시간 타이머 (분:초 형식)
- 토스트 알림 메시지

**URL:** `winter-student-portal.html`

---

### 3. **winter-weekly-schedule.html** - 주간 일정
**주요 기능:**
- 4주간 학습 계획 개요
- Week 1: 학습 습관 만들기 (1~7일)
  - 일일 상세 학습 계획 (Day 1~7)
  - 과목별 학습 내용 및 시간
  - 일일 완료 상태 (✅ 완료, ⚠️ 부족, 🎯 목표)
- Week 2: 취약 영역 강화 (8~14일)
- Week 3: 새학기 준비 (15~21일)
- Week 4: 종합 복습 & 계획 (22~30일)

**특징:**
- 7개 칼럼 그리드 레이아웃 (Day 1~7)
- 과목별 색상 구분 카드
- 진행 상황에 따른 잠금/해제 시스템
- 주간 목표 및 학습 가이드

**URL:** `winter-weekly-schedule.html`

---

### 4. **winter-materials.html** - 교재 관리
**주요 기능:**
- 수준별 교재 추천 시스템
  - **수학**: 체크체크(기초), 개념원리(내신), 일품/블랙라벨(최상위)
  - **영어**: Grammar Zone(기초), 천재 자습서+리딩튜터(내신), 리딩파워/능률보카(최상위)
- 국어, 과학, 사회 교재 추천
- 난이도 표시 (⭐⭐⭐⭐⭐)
- 권장 학년 및 특징 안내
- EBS 무료 강의 링크

**특징:**
- 3단계 수준별 분류 (기초/내신/최상위)
- 교재별 상세 설명 및 난이도 표시
- 외부 링크 (EBS 사이트)

**URL:** `winter-materials.html`

---

### 5. **winter-feedback.html** - 피드백
**주요 기능:**
- 주간별 피드백 제공
- Week 1 피드백 (완료)
  - 출석률, 학습시간, 달성률 통계
  - 강점 분석
  - 개선 포인트
  - 다음 주 목표
  - 담당 컨설턴트 및 작성일
- Week 2~4 피드백 (예정/대기중)

**특징:**
- 주간 완료 후 자동 잠금 해제
- 색상 구분 (완료: 녹색, 진행중: 파란색, 대기중: 회색)
- 구조화된 피드백 템플릿

**URL:** `winter-feedback.html`

---

### 6. **winter-report.html** - 학습 보고서
**주요 기능:**
- 프로그램 개요 (기간, 진행일, 진행률)
- 핵심 지표 4가지
  - 총 학습 시간
  - 출석률
  - 일일 평균
  - 평균 교재 진도
- Chart.js 기반 시각화
  - 주간 학습 시간 막대 차트
  - 교과별 분포 도넛 차트
- 교과별 상세 분석 (수학, 영어, 국어)
- 종합 평가 및 코멘트

**특징:**
- 데이터 기반 시각화
- 색상 코딩 (과목별)
- 우수/양호/개선 필요 구분
- 학습 성과 종합 평가

**URL:** `winter-report.html`

## 🚀 사용 방법

### 관리자 (선생님/컨설턴트)
1. `winter-index.html` 열기
2. 전체 학생 학습 현황 모니터링
3. `winter-weekly-schedule.html`에서 주간 계획 확인
4. `winter-feedback.html`에서 주간 피드백 작성
5. `winter-report.html`에서 종합 보고서 확인

### 학생
1. `winter-student-portal.html` 열기
2. 이름 입력 후 "찾기" 버튼 클릭
3. 과목별 "시작" 버튼으로 학습 시작
4. 학습 완료 후 "완료" 버튼 클릭
5. `winter-materials.html`에서 추천 교재 확인
6. `winter-weekly-schedule.html`에서 주간 계획 확인
