- 💪 **체력 관리**: 과다 학습 방지, 지속 가능성 ↑
- 📈 **효율성 증대**: 핵심 과목 집중으로 성적 향상

## ✅ 변경의 교육적 효과

### 1. 학습 효율성 증대
- **집중도 향상**: 5과목 → 3과목으로 분산 최소화
- **과목당 시간 증가**: 40~70분 → 70~120분
- **깊이 있는 학습**: 개념 이해 → 문제풀이 → 오답까지 완벽

### 2. 학생 부담 경감
- **주간 7시간 감소**: 32시간 → 25시간 (22% ↓)
- **체력 관리**: 과다 학습 방지
- **지속 가능성**: 3개월 이상 장기 학습 가능

### 3. 성적 향상 기대
- **핵심 과목 집중**: 수학, 영어 집중 투자
- **반복 학습**: 평일 학습 → 주말 복습 시스템
- **완벽 이해**: 충분한 시간으로 깊이 있는 학습

### 4. 학습 습관 형성
- **일관된 패턴**: 평일 3과목, 주말 3과목 고정
- **예측 가능성**: 매일 같은 시간, 같은 과목
- **자기주도학습**: 스스로 계획하고 실행하는 습관
