### 공부 시작하기
```
1. 공부할 과목 찾기
   예) 수학 숙제를 할 거면 → "수학" 찾기

2. "시작" 버튼 클릭
   → 타이머가 00:00:00부터 시작!
   → 00:00:01... 00:00:02... 올라감

3. 공부하기!
   → 타이머 신경 쓰지 말고 집중!
   → 브라우저 닫아도 타이머는 계속 돌아감
```

### 공부 중간에 쉬고 싶어요
```
✅ 괜찮아요!

→ "일시정지" 버튼 클릭
→ 타이머 멈춤
→ 다시 공부할 때 "시작" 버튼 클릭
→ 타이머 계속 진행!
```

### 공부 끝내기
```
⏰ 최소 30분은 공부해야 완료할 수 있어요!

1. 30분 이상 공부하면:
   → "완료" 버튼이 나타남!

2. "완료" 버튼 클릭:
   → 무엇을 공부했는지 입력하는 창이 나타남

3. 입력 항목:
   ✅ 교재: 교과서 또는 문제집 이름
   ✅ 페이지: 35-42쪽 (예시)
   ✅ 학습 내용: 무엇을 공부했는지 자유롭게 쓰기
      예) "소인수분해 개념 정리 및 문제 풀이"
      예) "영어 단어 50개 암기"

4. "저장" 버튼 클릭:
   → 완료! 🎉
   → 선생님이 확인할 수 있어요
```

```
수학 완료 → 10초 대기 → 다시 수학 시작 가능!

이유: 실수로 여러 번 클릭 방지
```

### 💡 Tip 4: 인터넷 없으면?

## ❓ 자주 묻는 질문 (FAQ)

### Q1. 30분을 꼭 채워야 하나요?
```
A. 네! 최소 30분은 공부해야 완료할 수 있어요.

이유: 짧은 시간은 제대로 된 공부가 아니에요.
집중해서 깊이 있게 공부하는 습관을 기르기 위해!
```

### Q2. 실수로 타이머를 잘못 눌렀어요!
```
A. "일시정지" 또는 "취소" 버튼을 누르세요.

아직 "완료"를 누르지 않았다면:
→ 데이터가 저장되지 않았어요
→ 다시 시작하면 됩니다!
```

### Q3. 학습 내용을 뭐라고 써야 하나요?
```
A. 정말 공부한 내용을 자유롭게 쓰세요!

좋은 예:
✅ "소인수분해 개념 정리, 문제집 35-42쪽 풀이"
✅ "영어 단어 50개 암기, 문법 정리"
✅ "국어 교과서 읽기, 문학 작품 감상문 쓰기"

나쁜 예:
❌ "공부함"
❌ "-"
❌ (빈칸)
```

### Q4. 선생님이 제 기록을 다 보나요?
```
A. 네, 선생님이 확인해요!

→ 언제 공부했는지
→ 얼마나 공부했는지
→ 무엇을 공부했는지

선생님이 피드백도 해주실 거예요! 💬
```

### Q5. 학교에서도 사용할 수 있나요?
```
A. 네! 어디서든 사용 가능해요!

✅ 집에서
✅ 학교에서
✅ 도서관에서
✅ 카페에서

인터넷만 있으면 OK!
```

### Q6. 부모님이 제 기록을 볼 수 있나요?
```
A. 현재는 선생님만 볼 수 있어요.

하지만 선생님이 부모님께 보여드릴 수 있어요!
(리포트 형식으로)
```

### Q7. 친구랑 비교할 수 있나요?
```
A. 아니요, 개인 기록이에요!

이유: 남과 비교하는 게 아니라,
      어제의 나보다 오늘의 내가 나아지는 게 중요해요! 💪
```

### Q8. 스마트폰으로도 되나요?
```
A. 네! 됩니다!

하지만 공부할 때는 PC를 권장해요.
(스마트폰은 유혹이 많아요... 😅)

추천:
→ 공부: PC에서
→ 기록 확인: 스마트폰에서도 OK
```

```
✅ 월요일부터 일요일까지

✅ 꾸준함이 가장 중요해요!

예시:
월: 수학 1시간 + 영어 1시간 = 2시간
화: 국어 1.5시간 + 과학 1시간 = 2.5시간
수: 수학 2시간 + 영어 1시간 = 3시간

```

```
나쁜 예:
월~금: 수학만 매일 3시간

좋은 예:
월: 수학 2시간 + 영어 1시간
화: 영어 2시간 + 국어 1시간
수: 국어 2시간 + 과학 1시간
...
```

### ⏰ 최적의 공부 시간
```
추천 시간대:

✅ 오후: 3-5시
✅ 저녁: 7-9시

피할 시간:
❌ 밤 11시 이후 (졸려요...)
❌ 점심 직후 (소화 중...)
```

### 🎯 목표 설정하기
```
스스로 목표를 정하세요!

- 영어: 주 5회 이상

목표 달성하면 스스로에게 보상! 🎁
```
