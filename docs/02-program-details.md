## 🌟 핵심 기능

### 1. 학생 포털 (Student Portal)

#### 1.1 학습 타이머
```
기능: 과목별 학습 시간을 실시간으로 측정

특징:
✅ 과목별 독립 타이머 (수학, 영어, 국어 등)
✅ 시작/일시정지/완료 기능
✅ 최소 학습 시간 30분 (변경 가능)
✅ 자동 시간 저장 (10초마다)
✅ 브라우저 종료 시에도 타이머 계속 실행
✅ 재로그인 시 타이머 자동 복원

작동 원리:
1. 학생이 "시작" 버튼 클릭
2. 타이머 시작 (00:00부터)
3. 10초마다 자동 저장 (localStorage)
4. 30분 이상 학습 후 "완료" 버튼 활성화
5. "완료" 클릭 시 Google Sheets에 자동 저장
6. 10초 쿨다운 (중복 저장 방지)

데이터 수집:
- start_time: 시작 시각 (HH:MM:SS)
- end_time: 종료 시각 (HH:MM:SS)
- time: 총 학습 시간 (분)
- study_duration: "44분 55초" 형식
```

#### 1.2 학습 기록 입력
```
기능: 학습 내용을 상세하게 기록

입력 항목:
✅ 교재/교과서 정보
✅ 페이지 범위 (예: 35-42쪽)
✅ 학습 내용 (예: 소인수분해, 최대공약수)

특징:
- 자유로운 텍스트 입력
- 자동 저장 (완료 시)
- 나중에 교사 대시보드에서 확인 가능
```

#### 1.3 진단평가
```
기능: 현재 실력을 파악하는 자가 진단

제공 문제:
✅ 수학: 10문항 (사칙연산, 방정식, 도형 등)
✅ 영어: 10문항 (문법, 독해, 어휘)
✅ 국어: 10문항 (문법, 독해, 어휘)

평가 결과:
- 총점 (예: 70점)
- 정답 개수 (예: 7/10)
- 오답 분석
- 개선 방향 제시

데이터 저장:
- 평가 날짜
- 과목
- 점수
- 상세 결과 (JSON)
```

#### 1.4 오늘의 총 학습시간
```
기능: 오늘 얼마나 공부했는지 실시간 확인

표시 방식:
"오늘의 총 학습시간: 2시간 30분"

특징:
- 모든 과목의 학습 시간 합산
- 실시간 업데이트
- 날짜 변경 시 자동 리셋 (00:00)
```

#### 1.5 중복 저장 방지
```
기능: 같은 과목을 10초 이내에 중복 저장 차단

작동:
1. 학생이 "완료" 클릭
2. 데이터 저장 시작
3. 10초 동안 같은 과목 "완료" 버튼 차단
4. 다른 과목은 즉시 저장 가능

목적:
- 실수로 여러 번 클릭 방지
- 데이터 중복 방지
- 시스템 안정성 향상
```

### 2. 교사 대시보드 (Teacher Dashboard)

#### 2.1 학생 관리
```
기능: 여러 학생을 한 화면에서 관리

표시 정보:
✅ 학생 이름
✅ 총 학습 시간 (누적)
✅ 학습 기록 개수
✅ 최근 학습 날짜
✅ 과목별 학습 시간

카드 형식:
┌─────────────────────────┐
│  김철수                  │
│  총 15시간 30분          │
│  기록 42개               │
│                         │
│  수학: 5시간             │
│  영어: 4시간             │
│  국어: 3시간             │
│                         │
│  [피드백 작성]           │
└─────────────────────────┘
```

#### 2.2 날짜별 필터링
```
기능: 특정 날짜의 학습 기록만 확인

사용 방법:
1. 상단 드롭다운에서 날짜 선택
2. 해당 날짜의 학생 카드만 표시
3. "전체 보기" 클릭 시 모든 기록 표시

활용:
- 일일 학습 현황 확인
- 주간/월간 비교
- 학부모 상담 자료
```

#### 2.3 검색 기능
```
기능: 학생 이름으로 빠른 검색

사용 방법:
1. 상단 검색창에 학생 이름 입력
2. 실시간으로 매칭되는 학생 표시
3. 부분 검색 지원 (예: "김" 입력 → "김철수", "김영희")

활용:
- 다수의 학생 중 특정 학생 빠른 찾기
- 상담 전 사전 확인
```

#### 2.4 피드백 작성
```
기능: 학생별, 날짜별 맞춤 피드백 작성

작성 방식:
1. 학생 카드 클릭 → 확장
2. 날짜별 학습 내용 확인
3. 피드백 입력창에 메시지 작성
4. "저장" 버튼 클릭

피드백 종류:
✅ 수동 피드백: 직접 작성
✅ AI 피드백: 자동 생성 (학습 데이터 기반)

저장:
- localStorage (브라우저 로컬)
- 새로고침 후에도 유지
- 나중에 수정 가능
```

#### 2.5 AI 자동 피드백
```
기능: 학습 데이터를 분석해 자동으로 피드백 생성

생성 기준:
- 학습 시간
- 과목별 분포
- 학습 내용
- 규칙성

예시:
"김철수 학생, 오늘 3시간 30분 동안 열심히 공부했네요! 
수학(2시간)과 영어(1시간 30분)에 집중한 모습이 보입니다. 
특히 소인수분해를 깊이 있게 학습한 점이 인상적입니다. 
내일은 국어도 조금 더 시간을 투자해보면 어떨까요?"

장점:
- 시간 절약 (클릭 한 번)
- 일관된 톤
- 데이터 기반 객관성
```

#### 2.6 엑셀 내보내기
```
기능: 학습 기록을 엑셀 파일로 다운로드

포함 정보:
✅ 학생 이름
✅ 날짜
✅ 과목
✅ 학습 시간 (시간/분 형식)
✅ 학습 횟수
✅ 학습 내용 (상세)
✅ 교사 피드백

파일명 형식:
"학습기록_2026-01-08.xlsx"

활용:
- 학부모 보고서
- 월간 리포트
- 데이터 백업
- 외부 분석
```

#### 2.7 통계 섹션
```
기능: 날짜별 학습 통계 요약

표시 정보:
✅ 날짜
✅ 학습한 학생 수
✅ 총 학습 시간 (모든 학생 합산)
✅ 학생당 평균 시간

예시:
┌────────────────────────────┐
│  통계                       │
│  날짜: 2026-01-08           │
│  학습한 학생 수: 15명        │
│  총 학습 시간: 45시간 30분   │
│  학생당 평균: 3시간 2분      │
└────────────────────────────┘

활용:
- 전체 학습 동향 파악
- 학생 참여율 확인
- 목표 달성 여부 점검
```

### 3. Google Sheets (데이터베이스)

#### 3.1 study_records 시트
```
열 구조:
A: id (학생 ID)
B: name (학생 이름)
C: date (날짜, YYYY-MM-DD)
D: subject (과목)
E: time (학습 시간, 분 단위)
F: content (학습 내용)
G: (상세 학습내용, 선택)
H: start_time (시작 시각, HH:MM:SS)
I: end_time (종료 시각, HH:MM:SS)
J: timestamp (저장 시각, ISO 형식)

예시 데이터:
| id | name | date | subject | time | content | start_time | end_time | timestamp |
|----|------|------|---------|------|---------|------------|----------|-----------|
| student_123 | 김철수 | 2026-01-08 | 수학 | 44 | 학습 완료 | 09:13:16 | 10:04:11 | 2026-01-08T01:04:11Z |

용도:
- 학생 포털에서 자동 저장
- 교사 대시보드에서 조회
- 엑셀 내보내기 소스
- 데이터 분석
```

#### 3.2 diagnostic_results 시트
```
열 구조:
A: id (학생 ID)
B: name (학생 이름)
C: date (날짜)
D: grade (학년)
E: subject (과목)
F: total_questions (총 문항 수)
G: correct_answers (정답 개수)
H: score (점수)
I: details (상세 결과, JSON)
J: timestamp (평가 시각)

예시 데이터:
| id | name | date | subject | total | correct | score | details |
|----|------|------|---------|-------|---------|-------|---------|
| student_123 | 김철수 | 2026-01-08 | 수학 | 10 | 7 | 70 | {...} |

용도:
- 진단평가 결과 저장
- 학생 실력 추이 분석
- 약점 파악
```

#### 3.3 teacher_feedback 시트
```
열 구조:
A: student_name (학생 이름)
B: date (날짜)
C: feedback (피드백 내용)
D: timestamp (작성 시각)

예시 데이터:
| student_name | date | feedback | timestamp |
|--------------|------|----------|-----------|
| 김철수 | 2026-01-08 | 오늘 열심히... | 2026-01-08T... |

용도:
- 교사 피드백 저장
- 피드백 이력 관리
- (현재는 localStorage 주로 사용)
```

## 🔧 기술 사양

### 프론트엔드 (Front-end)
```
언어: HTML5, CSS3, JavaScript (ES6+)
프레임워크: 없음 (Vanilla JS)
라이브러리:
  - SheetJS (XLSX): 엑셀 내보내기
  - Chart.js: 차트 (추후 추가 예정)
  
호스팅: GitHub Pages
URL:
  - 학생 포털: https://da-um3481.github.io/da-um-jinro/geunhwa-student-portal.html
  - 교사 대시보드: https://da-um3481.github.io/da-um-jinro/teacher-dashboard-simple.html

브라우저 지원:
  - Chrome 90+
  - Edge 90+
  - Safari 14+
  - Firefox 88+
  - 모바일 브라우저 (iOS Safari, Chrome Android)
```

### 백엔드 (Back-end)
```
플랫폼: Google Apps Script
언어: JavaScript (ES5 기반)
버전: v7.0.0

API 엔드포인트:
  POST /exec?action=saveStudyRecord
  POST /exec?action=saveDiagnosticResult
  POST /exec?action=saveTeacherFeedback
  GET /exec?action=getStudyRecords
  GET /exec?action=getDiagnosticResults
  GET /exec?action=getTeacherFeedback

응답 형식: JSON
```

### 데이터베이스 (Database)
```
플랫폼: Google Sheets
접근: Google Sheets API (via Apps Script)
백업: 자동 (Google Drive)
용량: 제한 없음 (실질적으로 무제한)

시트:
  1. study_records
  2. diagnostic_results
  3. teacher_feedback
```

### 저장소 (Storage)
```
로컬 저장: localStorage (브라우저)
  - 학생 정보 (studentId, studentName)
  - 진행 중인 타이머 정보
  - 오늘의 학습 기록 (임시)
  - 교사 피드백 (teacher-dashboard-simple.html)

클라우드 저장: Google Sheets
  - 영구 학습 기록
  - 진단평가 결과
  - 교사 피드백 (백업)
```

## ❓ FAQ

### Q1. 인터넷이 끊기면 어떻게 되나요?
```
A. 타이머는 계속 실행됩니다 (localStorage 저장).
   인터넷 연결 후 "완료" 버튼을 클릭하면 정상 저장됩니다.
```

### Q2. 브라우저를 닫으면 타이머가 멈추나요?
```
A. 아니요! 타이머는 시작 시각을 기록하므로,
   브라우저를 다시 열면 경과 시간이 자동으로 계산됩니다.
```

### Q3. 여러 기기에서 동시에 사용할 수 있나요?
```
A. 네, 가능합니다. 단, 각 기기의 데이터는 독립적으로 저장됩니다.
   Google Sheets에는 모두 저장되므로 교사 대시보드에서 확인 가능합니다.
```

### Q4. 데이터가 삭제될 위험은 없나요?
```
A. Google Sheets에 저장되므로 안전합니다.
   Google은 자동 백업 및 버전 관리를 제공합니다.
```

### Q5. 학생이 시간을 조작할 수 있나요?
```
A. localStorage는 조작 가능하나, Google Sheets에 저장된
   start_time/end_time을 비교하면 확인할 수 있습니다.
   (추후 검증 시스템 추가 예정)
```

### Q6. 비용은 얼마나 드나요?
```
A. 현재 시스템은 완전 무료입니다.
   - GitHub Pages: 무료
   - Google Sheets: 무료
   - Apps Script: 무료
   
   향후 유료 플랜 도입 시 공지 예정입니다.
```

### Q7. 모바일에서도 사용할 수 있나요?
```
A. 네, 모바일 브라우저에서 사용 가능합니다.
   (iOS Safari, Chrome Android)
   
   단, PC 사용을 권장합니다 (더 나은 UX).
```

### Q8. 학부모가 자녀의 학습 기록을 볼 수 있나요?
```
A. 현재는 교사 대시보드에서만 확인 가능합니다.
   학부모 포털은 추후 개발 예정입니다.
```

### Q9. AI 피드백의 정확도는 어느 정도인가요?
```
A. 학습 데이터(시간, 과목, 내용)를 기반으로 생성됩니다.
   참고용으로 사용하시고, 최종 피드백은 교사가 직접 작성하시는 것을 권장합니다.
```

### Q10. 시스템 업데이트는 어떻게 하나요?
```
A. GitHub Pages 자동 배포로, 코드 변경 시 2-3분 내 자동 업데이트됩니다.
   학생/교사는 브라우저 새로고침(Ctrl+Shift+R)만 하면 됩니다.
```
