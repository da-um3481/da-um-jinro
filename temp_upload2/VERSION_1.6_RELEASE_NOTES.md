## 📋 업데이트 요약

이번 업데이트는 **평일 4시간, 주말 6시간** 학습 목표를 완벽하게 자동화하여, 학생들이 요일에 맞는 맞춤형 학습 계획을 자동으로 받을 수 있도록 개선하였습니다.

---

## ✨ 주요 변경사항

### 1. 평일/주말 자동 구분 시스템 (핵심 기능)

#### 📱 학생 포털 자동 인식
학생이 포털에 접속하면 시스템이 **오늘의 요일을 자동 인식**하여:
- 목표 시간 자동 설정 (평일 4시간, 주말 6시간)
- 학습 내용 자동 조정 (평일: 복습 중심, 주말: 총복습 + 문제풀이)
- UI 색상 자동 변경 (평일: 파란색, 주말: 주황색)

#### ⏰ 목표 시간 차별화

**평일 (월~금) - 240분 (4시간)**
```
국어: 45분
영어: 45분
수학: 70분 ← 중점 과목
과학: 40분
사회: 40분
──────────
합계: 240분
```

**주말 (토~일) - 360분 (6시간)**
```
국어: 60분
영어: 60분
수학: 90분 ← 집중 학습
과학: 75분
사회: 75분
──────────
합계: 360분
```

**주간 총 목표: 32시간**
- 평일: 4시간 × 5일 = 20시간
- 주말: 6시간 × 2일 = 12시간

### 2. 학습 내용 차별화

#### 평일 학습 (복습 중심)
```
📖 [과목명] 오늘 학교수업 복습 + 교재 개념학습 + 기본문제
```

**특징**:
- 학교에서 배운 내용 당일 복습
- 교재를 통한 개념 정리
- 기본 문제로 이해도 확인

#### 주말 학습 (총복습 + 문제풀이)

**일반 과목**:
```
📚 [과목명] 주간 학습내용 전체 복습 + 핵심 개념 정리 + 문제풀이
```

**수학 (특별 구성)**:
```
📊 수학 이번 주 배운 단원 총복습 + 유형별 문제풀이 + 오답정리
```

**특징**:
- 평일에 배운 내용 전체 복습
- 주간 핵심 개념 재정리
- 단원별 종합 문제 풀이
- 오답 노트 작성 및 개념 보완
