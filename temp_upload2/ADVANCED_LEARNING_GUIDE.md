# 🚀 선행학습 프로그램 가이드

## 📋 개요

**상위권 학생을 위한 맞춤형 선행학습 시스템**으로, 평균 80점 이상의 우수 학생들이 다음 학기 또는 고등학교 1학년 1학기 내용을 체계적으로 선행할 수 있도록 지원합니다.

---

## 🎯 프로그램 목적

### 1. 상위권 학생의 학업 도약
- 현재 내신을 안정적으로 유지하면서
- 다음 단계를 미리 준비
- 학습 부담을 분산하여 여유 있게 선행

### 2. 70% 원칙
- **전체 내용의 70%만 목표**
- 100% 완벽을 추구하지 않음
- 개념 이해와 기본 문제 위주
- 나머지 30%는 정규 수업에서

### 3. 체계적 관리
- 주차별 상세 계획
- 진도율 실시간 추적
- 추천 교재 및 EBS 강의 제공

## 👥 대상 학생

### 자동 필터링 기준
```
평균 성적 80점 이상
= (국어 + 영어 + 수학 + 과학 + 사회) ÷ 5 ≥ 80점
```

### 추천 대상
- ✅ 현재 학기 내용을 완벽히 이해한 학생
- ✅ 자기주도학습 능력이 있는 학생
- ✅ 추가 학습 시간을 확보할 수 있는 학생
- ✅ 상위권 진학을 목표로 하는 학생

### 비추천 대상
- ❌ 현재 학기 내용도 불안정한 학생
- ❌ 기본 개념이 부족한 학생
- ❌ 학습 부담이 이미 큰 학생

## 📊 진도율 계산 방식

### 과목별 진도율
```
과목별 진도율 = (완료한 주차 수 / 전체 주차 수) × 100
```

예시:
- 수학 전체 12주차 중 8주차 완료
- 수학 진도율 = (8 / 12) × 100 = 66.7%

### 전체 진도율
```
전체 진도율 = (모든 과목 진도율 합) / 과목 수
```

예시:
- 수학 67%, 영어 75%, 과학 58%
- 전체 진도율 = (67 + 75 + 58) / 3 = 66.7%

### 목표 달성 판정
```
✓ 달성: 과목별 진도율 ≥ 목표 진도율
```

## 💡 효과적인 선행학습 방법

### 1. 70% 원칙 준수
```
❌ 나쁜 예: 한 단원을 100% 완벽하게
✅ 좋은 예: 전체를 70% 수준으로
```

**이유**:
- 완벽주의는 진도를 늦춤
- 개념 이해와 기본 문제가 중요
- 심화는 정규 수업에서

### 2. 개념 이해 중심
```
개념 강의 (40%) → 개념 정리 (30%) → 기본 문제 (30%)
```

**심화 문제는 스킵**:
- 선행의 목표는 "익숙해지기"
- 심화는 나중에 다시 학습

### 3. EBS 강의 적극 활용
```
1. 강의 시청 (2배속 권장)
2. 핵심 노트 정리
3. 기본 문제 풀이
4. 이해 안 되면 다시 시청
```

**장점**:
- 무료
- 언제든 반복 가능
- 좋은 강사진

### 4. 복습 주기
```
- 학습 직후: 5분 복습
- 1일 후: 10분 복습
- 1주 후: 15분 복습
```

**선행은 복습이 더 중요**:
- 한 번 보고 끝이 아님
- 반복해서 익숙해지기

### 5. 교재 활용법
```
[1회독] 개념 위주로 빠르게
[2회독] 기본 문제 풀면서
[3회독] 정규 수업 시작 전 정리
```

## ⚠️ 주의사항

### 1. 현재 학기 우선
```
❌ 현재 내신 70점인데 선행
✅ 현재 내신 80점 이상 유지하면서 선행
```

**선행보다 현재가 중요**

### 2. 과욕 금지
```
❌ 모든 과목 100% 목표
✅ 주요 과목 70% 목표
```

**욕심내면 다 망가짐**

### 3. 균형 유지
```
❌ 하루 5시간 선행학습
✅ 하루 1-2시간 꾸준히
```

**번아웃 주의**

### 4. 정규 수업 집중
```
선행은 "미리 보기"
정규 수업에서 "완벽하게"
```

**선행 = 100% 아님**

### 5. 휴식도 중요
```
주 6일 학습 → 1일 완전 휴식
```

**쉬어야 오래 간다**

## 📞 FAQ

### Q1: 평균 79점인데 선행해도 되나요?
**A**: 현재 학기를 먼저 80점 이상으로 올리세요. 선행은 그 다음입니다.

### Q2: 100% 완벽하게 하고 싶어요.
**A**: 선행의 목적은 "익숙해지기"입니다. 70%면 충분합니다.

### Q3: 학원 선행과 차이점은?
**A**: 
- 학원: 진도 빠르게, 100% 목표
- 우리: 70% 목표, 여유롭게, 자기주도

### Q4: 모든 과목 선행해야 하나요?
