🚀 A) GitHub Pages 완전정복 가이드

📌 GitHub가 뭔가요?

GitHub = 파일을 안전하게 보관하고 인터넷으로 공유할 수 있는 곳

GitHub Pages = 그 파일을 인터넷 주소로 만들어주는 기능 (무료!)

예: https://yourname.github.io/daum → 학생들이 여기로 접속!

1 GitHub 가입하기 (5분)
  1. https://github.com 접속
  2. 오른쪽 위 "Sign up" (가입하기) 클릭
  3. 정보 입력:
    • Email: 당신 이메일 (예: rami@naver.com)
    • Password: 비밀번호 (안전하게!)
    • Username: daum-rami (나중에 주소가 됨!)
  4. 이메일 인증 (메일 확인)
  5. ✅ 가입 완료!

⚠️ Username 중요!

Username이 daum-rami면:

→ 주소가 https://daum-rami.github.io가 됩니다!

간단하고 기억하기 쉬운 이름으로 하세요!

2 프로젝트 만들기 (3분)
  1. GitHub 로그인한 상태에서
  2. 오른쪽 위 "+" 버튼 클릭
  3. "New repository" 클릭
  4. 정보 입력:
    • Repository name: daum-system
    • Description: "DA.UM 학습관리 시스템"
    • Public 선택 (무료로 공개)
    • "Add a README file" 체크
  5. 맨 아래 "Create repository" 버튼 클릭
  6. ✅ 프로젝트 생성 완료!
3 파일 업로드하기 (10분)
  1. 방금 만든 프로젝트 화면에서
  2. "Add file" 버튼 클릭
  3. "Upload files" 선택
  4. 중요! 업로드할 파일들:
    • ✅ index.html
    • ✅ students.html
    • ✅ students-bulk-upload.html
    • ✅ schools-management.html
    • ✅ student-portal.html
    • ✅ winter-student-portal.html
    • ✅ css 폴더 (전체)
    • ✅ js 폴더 (전체)
    • ✅ images 폴더 (전체)
    • ✅ 모든 HTML 파일들
  5. 드래그해서 올리거나 "choose your files" 클릭
  6. 맨 아래 "Commit changes" 클릭
  7. ✅ 업로드 완료!

⚠️ 폴더를 통째로 업로드하세요!

파일만 올리지 말고 css, js, images 폴더도 함께 올려야 합니다!

4 GitHub Pages 켜기 (2분)
  1. 프로젝트 화면 상단의 "Settings" 클릭
  2. 왼쪽 메뉴에서 "Pages" 클릭
  3. "Source" 아래에서:
    • Branch: "main" 선택
    • Folder: "/ (root)" 선택
  4. "Save" 버튼 클릭
  5. 1~2분 기다리기 (자동으로 사이트 만드는 중...)
  6. 페이지 새로고침 (F5)
  7. 위에 초록색 박스에 주소가 나타남:
    🎉 https://daum-rami.github.io/daum-system
  8. ✅ 완료! 이제 인터넷 주소가 생겼습니다!
5 테스트하기 (5분)
  1. 생성된 주소를 복사: https://daum-rami.github.io/daum-system
  2. 새 탭에서 열기
  3. 확인할 것:
    • ✅ index.html이 잘 보이나요?
    • ✅ 학생 포털도 되나요? (주소 뒤에 /student-portal.html 추가)
    • ✅ 학교 관리도 되나요? (주소 뒤에 /schools-management.html 추가)
  4. ✅ 모두 잘 되면 성공!

❓ 자주 묻는 질문

Q1. 파일을 수정하면 어떻게 하나요?

A: GitHub에서 수정하거나, 다시 업로드하면 됩니다.

  1. GitHub 프로젝트 페이지 가기
  2. 수정할 파일 클릭
  3. 연필 아이콘 (Edit) 클릭
  4. 수정 후 "Commit changes" 클릭
  5. 1~2분 후 사이트에 자동 반영!

Q2. 주소가 너무 길어요

A: 짧은 주소로 만들 수 있어요! (무료)

  • bit.ly 사용: https://bit.ly/daum-student
  • QR코드 생성: 학생들이 스마트폰으로 스캔!

Q3. 비용이 정말 0원인가요?

A: 네! GitHub Pages는 완전 무료입니다.

단, 제한사항:

  • 저장 용량: 1GB (충분함)
  • 월 트래픽: 100GB (학생 100명도 OK)
  • 빌드 시간: 월 10시간 (충분함)

Q4. 나중에 도메인 (daum.co.kr) 사고 싶어요

A: 가능합니다! (나중에)

  • 가비아에서 도메인 구매 (연 1만원~)
  • GitHub Pages 설정에서 연결
  • → https://daum.kr 같은 주소 사용 가능!

Q5. GitHub 비밀번호를 잊어버렸어요!

A: 로그인 화면에서 "Forgot password" 클릭하면 이메일로 복구 가능합니다.

💡 팁: 비밀번호를 노트에 적어두세요! (안전한 곳에)

🔧 문제 해결

❌ 404 Not Found 에러가 나요

원인: 파일이 제대로 업로드 안 됨

해결:

  1. GitHub 프로젝트로 가기
  2. index.html 파일이 보이는지 확인
  3. 없으면 다시 업로드

❌ CSS/이미지가 안 보여요

원인: 폴더 구조가 잘못됨

해결:

  1. css, js, images 폴더가 있는지 확인
  2. 폴더 안에 파일들이 있는지 확인
  3. 없으면 폴더째로 다시 업로드

❌ 수정했는데 반영이 안 돼요

원인: 캐시 때문 (브라우저가 옛날 버전을 보여줌)

해결:

  1. Ctrl + F5 눌러서 새로고침
  2. 또는 시크릿 모드로 열기
  3. 5분 정도 기다려보기
