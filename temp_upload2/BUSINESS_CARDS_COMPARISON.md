### 🔷 스타일 1: 클래식 프로페셔널

#### 디자인 특징
```
앞면: 네이비 그라데이션 배경 + 화이트 텍스트
뒷면: 화이트 배경 + 네이비 포인트
장식: 원형 패턴 (미니멀)
폰트: Montserrat (영문), Noto Sans KR (한글)
```

#### 컬러 심리
- **네이비 블루**: 신뢰, 안정, 전문성, 지적
- **화이트**: 깨끗함, 명확함, 순수함

#### 타깃 분석
```
✅ 최적:
   • 학교 교장/교감 선생님
   • 교육청 관계자
   • 공식 교육 행사
   • 학부모회 임원

❌ 비추천:
   • 젊은 층 (20-30대)
   • 캐주얼한 분위기
   • SNS 마케팅용
```

#### 활용 시나리오
```
📍 상황 1: 학교 공식 미팅
"교장선생님, 만나 뵙게 되어 영광입니다.
저는 다움진로진학컨설팅의 정라미입니다."
→ 신뢰감 있는 네이비 명함 전달

📍 상황 2: 교육청 방문
"저희 프로그램을 소개하고 싶어 찾아뵙게 되었습니다."
→ 공식적인 느낌의 명함이 적합

📍 상황 3: 학부모회 미팅
"학부모님들의 자녀 진로 상담을 돕고 있습니다."
→ 전문성 강조
```

#### 장점 vs 단점
| 장점 | 단점 |
|------|------|
| ✅ 신뢰감 높음 | ❌ 다소 보수적 |
| ✅ 전문성 강조 | ❌ 젊은 감각 부족 |
| ✅ 공식 행사에 적합 | ❌ 차별화 약함 |
| ✅ 모든 연령대 무난 | ❌ 기억에 덜 남음 |

#### 인쇄 권장 사양
```
용지: 스노우지 250g
코팅: 무광 (필수)
모서리: 일반 또는 라운드 1mm
수량: 500매
```
