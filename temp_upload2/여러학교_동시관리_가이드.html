🏫 여러 학교 동시 관리 가이드

중학교, 고등학교, 개별 학생을 한 곳에서 관리하세요!

✅ 이제 가능합니다!

  • A중학교 30명 + B중학교 25명 → 섞이지 않고 독립 관리
  • 겨울방학 프로그램 + 100일 프로그램 → 프로그램별 분류
  • 중학생 + 고등학생 → 학년 구분 자동
  • 개별 학생 → 학교 없이 1:1 관리
시나리오 1: 첫 학교 등록 (1월 시작)
1 학교 등록하기
  1. schools-management.html 파일 열기
  2. 상단 폼에 정보 입력:
    • 학교명: "A중학교"
    • 유형: "🏫 중학교" 선택
    • 계약 시작일: 2025-01-02
    • 계약 종료일: 2025-02-28
    • 월 계약금액: 1,500,000원
    • 학생 수: 30명
    • 담당자: 김선생님
    • 연락처: 010-1234-5678
    • 계약 상태: "✅ 활성" 선택
    • 주 프로그램: "❄️ 겨울방학 30일" 선택
  3. "저장" 버튼 클릭
  4. ✅ 완료! 학교 목록에 A중학교가 나타남
2 학생 30명 일괄 등록
  1. students-bulk-upload.html 파일 열기
  2. 맨 위 선택 박스에서:
    • 학교/기관 선택: "🏫 A중학교" 선택
    • 프로그램 선택: "❄️ 겨울방학 30일" 선택
    • 학생 유형: "🏫 중학생" 선택
  3. "엑셀 템플릿 다운로드" 버튼 클릭
  4. 엑셀에 30명 학생 정보 입력 (학년: 1, 2, 3)
  5. 파일 저장 후 업로드
  6. ✅ 완료! A중학교 학생 30명 등록
3 학생 확인하기
  1. students.html 파일 열기
  2. 필터에서 "🏫 A중학교" 선택
  3. ✅ A중학교 학생 30명만 표시됨!
시나리오 2: 두 번째 학교 추가 (3월)
1 B중학교 등록
  1. schools-management.html 열기
  2. 새 학교 정보 입력:
    • 학교명: "B중학교"
    • 유형: "🏫 중학교"
    • 월 계약금액: 1,250,000원 (25명)
    • 주 프로그램: "📚 정규학기 100일"
  3. 저장
2 B중학교 학생 25명 등록
  1. students-bulk-upload.html 열기
  2. 학교: "🏫 B중학교" 선택
  3. 프로그램: "📚 정규학기 100일" 선택
  4. 템플릿 다운로드 → 25명 입력 → 업로드
  5. ✅ B중학교 학생 25명 등록

💡 중요! A중학교와 B중학교가 섞이지 않습니다!

students.html에서 필터로 학교를 선택하면:

  • A중학교 선택: 30명만 표시
  • B중학교 선택: 25명만 표시
  • 전체 선택: 55명 모두 표시
시나리오 3: 고등학교 + 개별 학생
1 고등학교 등록
  1. schools-management.html 열기
  2. 학교명: "C고등학교"
  3. 유형: "🎓 고등학교" 선택
  4. 학생 수: 20명
  5. 저장
2 고등학생 등록
  1. students-bulk-upload.html 열기
  2. 학교: "🎓 C고등학교" 선택
  3. 학생 유형: "🎓 고등학생" 선택 ⭐
  4. 템플릿 다운로드
  5. 엑셀에 학년: 4, 5, 6 입력 (고1, 고2, 고3)
  6. 업로드 완료!
3 개별 학생 등록 (학교 소속 없음)
  1. schools-management.html에서:
    • 학교명: "개별학생"
    • 유형: "👤 개별학생" 선택
    • 저장
  2. students.html에서:
    • 학교: "👤 개별학생" 선택
    • 프로그램: "✨ 맞춤형" 선택
    • 학생 이름, 학년 등 입력
    • 저장
  3. ✅ 1:1 맞춤 관리 학생 등록 완료!

❓ 자주 묻는 질문

Q1. 학교를 먼저 등록해야 하나요?

A: 네! 학생을 등록하기 전에 반드시 학교를 먼저 등록해야 합니다.

순서: schools-management.html → students-bulk-upload.html

Q2. 학교를 잘못 선택했어요

A: students.html에서 학생을 찾아서 "수정" 버튼을 누르면 학교를 변경할 수 있습니다.

Q3. 학년 4, 5, 6이 뭔가요?

A:

  • 중학생: 1(중1), 2(중2), 3(중3)
  • 고등학생: 4(고1), 5(고2), 6(고3)

Q4. 한 학생이 두 프로그램에 동시 참여 가능한가요?

A: 현재는 불가능합니다. 한 학생은 하나의 프로그램에만 속합니다.

필요하면 같은 학생을 다른 프로그램으로 다시 등록해야 합니다.

⚠️ 중요 주의사항

  • 학교를 먼저 등록하지 않으면 학생 등록 시 선택할 학교가 없습니다!
  • 학교와 프로그램을 반드시 선택해야 합니다. 안 하면 나중에 구분 불가!
  • 학년 번호 주의: 중학생(1,2,3) / 고등학생(4,5,6)
