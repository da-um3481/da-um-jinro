💡 학생 데이터는 어떻게 저장되나요?

🗄️ localStorage 사용

당신의 시스템은 브라우저 localStorage를 사용합니다.
이것은 무료이고 자동으로 작동합니다!

장점:

  • ✅ 완전 무료
  • ✅ 서버 필요 없음
  • ✅ 빠름
  • ✅ 설정 불필요

단점 (학생 3명에겐 문제 없음):

  • ⚠️ 브라우저마다 독립적 (Chrome에서 입력하면 Chrome에만 저장)
  • ⚠️ 캐시 삭제 시 데이터 손실 가능 → 해결책: 주간 백업!

⚠️ 데이터 백업하는 법 (주 1회, 5분)

  1. 브라우저 F12 누르기 (개발자 도구)
  2. Application 탭 클릭
  3. Local Storage 확장
  4. 모든 데이터 복사
  5. 메모장에 붙여넣기
  6. 파일 저장 (예: backup_2025_01_15.txt)

💡 또는 그냥 report.html 스크린샷 저장!
