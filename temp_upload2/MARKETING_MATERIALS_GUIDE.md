## 1. 마케팅 자료 개요

### 🎯 목적

이 프로그램은 **중학교 방과후 학습 관리 시스템**으로, 다음의 핵심 가치를 제공합니다:

- **사교육비 98% 절감** (월 90만원 → 5만원)
- **평균 +15점 성적 향상** (100점 만점 기준)
- **자기주도학습 습관 형성** (주 32시간 체계적 관리)
- **실시간 교사-학생 연동** (30초 자동 새로고침)

### 🎨 제작 철학

1. **교육적 가치 우선**: 단순한 프로그램이 아닌 교육 혁신 도구
2. **데이터 기반 설득**: 실증된 성과와 통계로 신뢰도 확보
3. **맞춤형 접근**: 학교 유형별 (공립/사립/소규모) 차별화 전략
4. **비주얼 임팩트**: 전문적이고 현대적인 디자인으로 신뢰감 조성

- 홍보 실행 플랜

### 📑 2. 학교 제안서 (marketing-proposal.html)

**파일명**: `marketing-proposal.html`  
**형식**: HTML (프린트 가능)  
**용도**: 학교 교장/교감 선생님께 제출용 공식 문서

**주요 내용**:
- **10페이지 구성**
  1. 표지 (프로그램 핵심 지표)
  2. 목차
  3. 제안 배경 - 교육 현장의 위기
  4. 프로그램 개요 및 목적
  5. 시스템 소개 및 핵심 기능
  6. 운영 프로세스
  7. 경쟁 우위 및 차별화
  8. 실증 데이터 및 성과
  9. 비용 및 투자 효과
  10. 도입 제안 및 다음 단계

**특징**:
- 프로페셔널한 디자인 (Tailwind CSS)
- 통계 시각화 (차트, 그래프)
- 인쇄 최적화 (A4 용지)
- 색상 코딩 (섹션별 구분)

**사용 방법**:
```bash
1. 브라우저에서 marketing-proposal.html 열기
2. Ctrl+P (인쇄)
3. PDF로 저장 또는 직접 인쇄
4. 학교 방문 시 제출
```

  5. 4가지 핵심 목표
  6. 교사용 대시보드
  7. 학생용 포털

  9. 일일 학습 루틴
  10. 4 ONLY 차별화
  11. 실증 데이터
  12. 실제 사용 후기
  13. 비용 비교
  14. 학교별 맞춤 제안

**특징**:
- 전체화면 슬라이드 형식
- 키보드 네비게이션 (← / → / Space)
- 슬라이드 번호 표시

- 애니메이션 효과

**사용 방법**:
```bash
1. 브라우저에서 marketing-presentation.html 열기
2. F11 (전체화면)
3. 화살표 키 또는 하단 버튼으로 이동
4. 발표 진행

**발표 시나리오** (30분):
```

02:00-05:00  Slide 5-9   시스템 소개 및 작동 방식
05:00-08:00  Slide 10-11 차별화 및 성과 데이터
08:00-12:00  Slide 12-13 사용 후기 및 비용 비교
12:00-15:00  Slide 14-15 맞춤 제안 및 다음 단계
15:00-30:00  질의응답

- 문제 제기 (학부모/학생/교사 고민)
- 솔루션 (교사/학생 포털)
- 작동 방식 (5단계 시각화)
- 차별화 포인트 (4 ONLY)
- 실증 데이터 및 성과
- 실제 사용 후기
- 비용 비교
- CTA (무료 상담 신청)
- Footer (운영 정보)

**특징**:
- 모바일 우선 설계 (Mobile First)
- 1페이지 스크롤 형식
- 밝고 현대적인 UI
- 터치 최적화
- 빠른 로딩

**사용 방법**:
```bash
# 온라인 공유
1. 웹 호스팅에 업로드
2. URL 생성
3. 카카오톡, 학교 홈페이지, SNS 공유

# QR 코드 생성
1. URL을 QR 코드로 변환
2. 리플렛, 포스터에 삽입
3. 학부모 설명회에서 배포
```

## 3. 자료별 사용 방법

### 📅 상황별 최적 자료 선택

| 상황 | 추천 자료 | 이유 |
|------|----------|------|
| 교장 선생님 첫 미팅 | 제안서 (PDF) | 공식적이고 상세한 정보 제공 |
| 학교 설명회 (30분) | 프레젠테이션 | 시각적 임팩트 + 실시간 설명 |
| 학부모 대상 홍보 | 모바일 리플렛 | 스마트폰으로 쉽게 확인 |
| 교육청 제안 | 제안서 + 전략서 | 체계적이고 전문적인 접근 |
| 온라인 마케팅 | 모바일 리플렛 | SNS 공유 용이 |
| 내부 팀 교육 | 전략서 | 상세한 전략 및 배경 이해 |

### 🎤 발표 시나리오 (30분 표준)

#### Phase 1: 오프닝 (5분)
```
"안녕하세요. 다움진로진학컨설팅 정라미입니다.
오늘은 학교가 다시 교육의 중심이 될 수 있는 혁신적인 방법을 소개하고자 합니다."

[Slide 1: 표지]
"100일의 변화는 사교육비를 98% 절감하면서도 성적을 평균 15점 향상시키는
웹 기반 학습 관리 시스템입니다."

[Slide 2-3: 문제 제기]
"현재 중학생의 74.3%가 사교육을 받고 있으며, 
한 가정당 월 90만원, 3년간 3,240만원을 지출하고 있습니다.
그러나 막대한 비용에도 불구하고 자기주도학습 능력은 오히려 저하되고 있습니다."
```

#### Phase 2: 솔루션 제시 (10분)
```
[Slide 4-5: 우리의 솔루션 + 4가지 목표]
"우리는 '학교 수업을 최대한 활용하면 고액 사교육 없이도 성적을 올릴 수 있다'는
믿음을 실천하기 위해 이 프로그램을 개발했습니다."

[Slide 6-9: 시스템 소개]
"교사용 대시보드는 30초마다 자동 새로고침되어 학생들의 학습 현황을
실시간으로 모니터링할 수 있습니다.
학생용 포털은 시작/완료 버튼만 누르면 자동으로 시간이 기록되어
매우 간편합니다."
```

#### Phase 3: 차별화 및 성과 (7분)
```
[Slide 10-11: 차별화 + 데이터]
"우리만의 4가지 차별화 포인트는...
1) 담임 선생님의 직접 관리
2) 30초 내 실시간 반영
3) 학교 진도에 맞춘 맞춤형 계획
4) 월 5만원의 합리적 가격"

"실제 운영 결과, 평균 달성률 85%, 성적 향상 +15점,
3년간 3,060만원 절감 효과를 입증했습니다."
```

#### Phase 4: 실제 후기 및 비용 (5분)
```
[Slide 12-13: 후기 + 비용]
"실제 사용 학부모님들의 후기를 들어보시겠습니다.
'3개월 만에 아이 성적이 20점 올랐어요...'

비용을 비교해보면, 학원 90만원, 온라인강의 10만원, 학습앱 3만원,
그리고 우리 프로그램은 단 5만원입니다.
전문 관리와 저렴한 가격의 완벽한 균형입니다."
```

#### Phase 5: 마무리 및 CTA (3분)
```
[Slide 14-15: 맞춤 제안 + CTA]
"귀교의 유형에 맞는 맞춤형 패키지를 준비했습니다.
공립학교는 무료 파일럿 1개월, 사립학교는 프리미엄 패키지,
소규모 학교는 초저가 패키지를 제공합니다.

지금 시작하세요. 우리 학교가 교육 혁신의 중심이 됩니다."
```

#### Q&A (15분)
```
예상 질문 및 답변은 MARKETING_STRATEGY.md의
"예상 질문 및 대응 Q&A" 섹션 참조
```

## 4. 활용 시나리오

### 🏢 시나리오 1: 공립 중학교 접근

**Target**: 교장 선생님, 교감 선생님

**Step 1: 이메일 발송**
```
제목: [혁신 교육 제안] 사교육비 98% 절감하는 학습 관리 시스템

본문:
안녕하세요, 다움진로진학컨설팅 정라미입니다.

사교육 없이도 성적을 올릴 수 있는 혁신적인 학습 관리 시스템을
소개하고자 합니다.

- 사교육비 98% 절감 (월 90만원 → 5만원)
- 평균 성적 +15점 향상
- 담임 선생님의 실시간 학생 관리

첨부된 제안서를 참고하시고, 30분 데모 시연을 제안드립니다.

첨부: marketing-proposal.pdf

감사합니다.
```

**Step 2: 전화 Follow-up (3일 후)**
```
"교장 선생님, 이메일 확인하셨나요?
학교 방문하여 30분 데모 시연을 보여드리고 싶습니다.
언제 시간이 괜찮으실까요?"
```

**Step 3: 학교 방문 미팅**
```
준비물:
- 노트북 (프레젠테이션 준비)
- 제안서 인쇄본 3부 (교장, 교감, 부장)
- 명함
- 데모 계정

진행:
1. 프레젠테이션 시연 (15분)
2. 실제 시스템 데모 (10분)
3. 질의응답 (5분)
```

**Step 4: 무료 파일럿 제안**
```
"먼저 1개 학년, 1개월 무료로 체험해보시면 어떨까요?
비용 부담 없이 효과를 직접 확인하실 수 있습니다."
```

   - Slide 1-15 발표
   - 핵심 메시지 강조

3. 실제 시스템 데모 (10분)
   - 학생 포털 시연
   - 교사 대시보드 시연

4. 질의응답 (20분)
   - 학부모 질문 답변
   - 우려 사항 해소

5. 현장 신청 (5분)
   - 신청서 작성
   - QR 코드로 리플렛 공유
```

**핵심 메시지** (학부모 대상):
```
✓ "월 90만원 → 5만원, 3년간 3,000만원 절약"
✓ "학원보다 안전합니다 (집에서 학습)"
✓ "담임 선생님이 직접 관리합니다"
