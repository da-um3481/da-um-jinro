다운로드 후 GitHub 업로드 방법

1단계: GitHub 저장소에서 "Add file" → "Create new file"

2단계: 파일 이름에 입력: js/README.md

→ js/ 라고 쓰면 폴더가 자동 생성돼요!

3단계: 내용에 "JavaScript files" 입력 → Commit

4단계: "js" 폴더 클릭 → "Upload files"

5단계: 다운받은 js 파일 11개 드래그 → Commit
